# 山野 · 阵火

横屏手机网页游戏，以朱砂卷轴、水墨山林和五行战斗为视觉与玩法基础。开局五选二搭配神通，通过十波战斗发展杀伐、召唤或阵法构筑。

## 本地运行

```sh
npm ci
npm run dev
```

开发地址为 <http://127.0.0.1:5174/>。手机操作以点击、按住与手指拖划为主；页面禁止缩放。先天气运的选择按钮与底部入山栏保持可见，候选列表支持手指滚动。

## 当前玩法

- 杀伐围绕轻重刀搭配、蓄力、破甲和灵力收支展开。
- 召唤通过跃进、回防、重复、回血、进攻等命令控制召唤灵。
- 阵法使用划线残留的持续元素伤害，并通过相生相克连招取得收益。
- 灵力上限为 100，每波结束固定补充 50 并受上限限制；战斗恢复与技巧回气按流派结算。
- 怪物生命和攻击逐波乘以 1.1，精英数量与能力随波次推进。

完整规则与数值见 [三流派玩法、灵力经济与手机布局](./docs/design/35-style-economy-mobile.md)。其他设计文档保留开发过程中的方案，当前实现以源码为准。

首次点击后开启声音。图片、音频和开场视频准备完成后才允许进入；持续收到数据的下载不会被总时长限制打断。

## 构建与发布

```sh
npm run build
```

构建会执行 TypeScript 检查并生成 `web-release/`。该目录包含完整 HTML、脚本、图片、字体、音频和视频，可直接整包上传静态网站托管平台；网站与素材使用同站点相对路径。

GitHub 的 `master` 保存源码、素材与完整发布目录。后续在当前 `master` 修改、构建、提交和推送，不另建发布分支。已部署的平台是否自动更新取决于该项目的部署方式，Git 推送与直接上传是两个独立步骤。

Cloudflare 的现有配置见 [发布说明](./docs/cloudflare-pages.md)。腾讯 EdgeOne Makers 可选择“通过上传文件创建”，上传 `web-release/` 文件夹或将其内容压缩为 ZIP；压缩包根目录必须直接包含 `index.html`。使用国内临时预览地址时，分享链接需要保留完整查询参数，并留意平台显示的有效期。

## 项目结构

- `src/game/`：战斗、经济、敌人和构筑规则。
- `src/render/`：Canvas 场景、角色与特效。
- `src/ui/`：手机交互、卷轴界面、引导与加载。
- `public/`：运行素材及可编辑素材原稿。
- `scripts/`：素材制作与已有检查工具。
- `docs/`：设计方案、素材记录和发布说明。

本地部署凭据、临时包和运行记录不提交到仓库。
