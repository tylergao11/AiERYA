# 山野 · 阵火

2D 美漫插画风的森林阵法塔防。年轻阵法师在夜间营地借取五行灵力，按自己画出的闭合形状生成阵法，抵挡狼群，再用划线引动环境与阵域。

视觉目标：**在插画中玩游戏，浑然天成。** 背景保持简洁，把重点留给玩家布阵；天然溪流与水阵共用动态水体，篝火与火阵共用火焰。当前三维场景、模型和 Three.js 依赖已移除。

## 运行

```sh
npm install
npm run dev
```

访问 <http://127.0.0.1:5174/>。使用此 IPv4 地址，避免与其他项目的 localhost 服务混淆。

点击场景资源取材，选择五行，在空地画闭合形状布阵。迎战后切换引动，划过自然环境或已有阵法。Q / E 切换操作，1–5 选择五行，空格暂停，滚轮缩放。

`src/game` 管理规则与状态，`src/render` 使用 Canvas 2D 绘制插画、角色和事件特效，`src/ui` 管理界面与输入。美术和玩法分工推进，水灵辅助攻击是后续肉鸽方向，尚未实现。

当前三波战斗、点击取材与波间数值升级用于试玩，具体数值仍由玩法工作调整。

## 验证与素材

`npm test` 检查规则、凹形阵法和坐标投影，`npm run build` 检查 TypeScript 与生产构建。页面截图和动态检查用于验证美术呈现，手机性能仍需真机验证。

插画与序列帧来自本项目内置图像生成工具的制作流程，详情见 [素材记录](./public/art/README.md)。
