# 战斗音频调优

2026-09-13。用户确认反复的“噔噔噔”在开战后明显，要求全项目声音更利落、减少幽怨和听觉疲劳。

## 已落实的修改

- 删除 `Soundscape.chime()` 的正弦音及下滑音高。旧实现每次常规命中最短 160 ms 追加一声 130 Hz 低音，和流派材质命中音重叠；当前三个流派只保留各自命中声，原型模式使用短材质接触音。
- 重写全局配乐为 96 BPM、48 小节、120 秒。六段开放五声旋律、柔和长弓音和短鼓错落编排，每八小节收束；主题不含反复拨弦或低锣。音乐按已有战况平滑进入战斗、压力与狼王层，不增加来袭预告。
- 通用按钮、修营、布阵、施法和营地受击改为短木石、风和五行材质；胜利以明亮五声收束，失败缩短尾音。精英保留动作声线，降低远处声量和普通扑咬、死亡的密度。
- 普通脚步至少行进 2.4 个世界单位才有机会发声，同类全局间隔 290 ms，神速和巨躯至少 700 ms。精英实际回生提示间隔 6 秒。危险声只在低血且近营有敌时触发，后续至少再损失 10 点生命并间隔 12 秒，稳定低血量不定时报警。
- 杀伐回灵提示降至原音量的 40%，间隔 600 ms；阵法自动脉冲和传阵提示收轻。各流派技能素材、攻击时机及专属 UI 保持原有归属。
- 三条公共通道加入低切、温和削减存在感频段与高切：音乐 85 Hz–8.5 kHz，音效 55 Hz–11.5 kHz，环境 110 Hz–7 kHz。保留动态避让、分项音量与主输出限幅；总音量或音效调至零时清理短音，恢复音量不补播。
- 全局媒体 URL 加入音频内容版本，防止新代码读取浏览器缓存的旧音轨。开场短片测得峰值 −2.06 dBFS、均方根 −19.88 dBFS，继续遵循原有主音量和音乐音量，无需改动视频媒体。
- 修复界面暂停策略：天赋、奖励和结算面板继续播放安静配乐及完整尾音；玩家主动暂停或切到后台才暂停音频时钟，声音设置保留试听。

## 制作与验证入口

制作：`node scripts/build-forest-audio.mjs`；双编码检查：`node scripts/verify-forest-audio.mjs`。素材授权仍由 `public/audio/README.md` 与对应 CC0 文件记录。

音频回归覆盖三流派、资源、共享通道和生命周期，新增密集命中不叠通用声、低血不周期报警、零音量清除旧声的检查。实机录制脚本在 `artifacts/audio-rework/runtime-fixture.js`：使用开发场景的真实混音器、流派和敌人事件，测试夹具补充敌人、灵力与营地生命，覆盖三流派、96 狼压力、狼王、胜败和重开；该夹具不用于证明游戏平衡或通关能力。

自动化和输出波形检查可以证明声音调度、峰值与循环连续性，不能代替耳机、手机外放上的主观听感评审。当前未将这两种设备试听标为完成。

## 本轮验证结果

- `npx vitest run --maxWorkers=2 --testTimeout=20000`：66 个文件、743 条测试通过。默认并发曾造成耗时仿真超时；另外修正两条仍假设篝火不杀敌的旧断言，保留活狼上限、暂停停止来袭、简陋防御不能通关等约束。日志：`artifacts/audio-rework/final-tests.log`。
- 最后补充静态面板暂停策略后，四个音频测试文件 51 条全部通过，并重新通过 TypeScript 与生产构建；见 `audio-final-tests.log` 与 `build.log`。全量结果在该补充之前，未冒称重新跑过全量。
- 最终界面实测未强制解除音频暂停：初始天赋、奖励、胜利及重开后的天赋均保持音频运行；胜利 900 ms 后仍有结算声播放。手动暂停变为 suspended，继续后恢复 running。证据：`panel-audio-review.json`。
- 双编码 14 个文件完整解码，最坏单轨峰值 −4.04 dBFS，最坏循环端点差 0.00331，未检出削波。
- 浏览器实录 141.84 秒，实际覆盖 quiet、battle、pressure、king、won、lost 六种音乐状态，最高 96 个活敌。全局峰值 −2.46 dBFS、均方根 −25.65 dBFS，无饱和采样或页面错误。
- 全局短音最高并发 9；杀伐 4、召唤 5、阵法 4，各自产生 87、75、107 次真实播放。六个循环始终保持六个，重开与暂停后所有短音归零。三流派分别实测音效归零、总音量归零、静音和暂停，全部清理旧声，恢复不补播。
- 证据：`artifacts/audio-rework/runtime-review.webm`、`runtime-review.json`、`analysis.json`、`lifecycle.json`。36 秒实录剪辑 `battle-audio-preview.wav` 没有额外音量归一化，依次为环境、杀伐、召唤、阵法、狼王与胜利。
