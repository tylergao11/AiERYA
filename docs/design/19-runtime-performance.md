# 运行性能与手机适配

本轮负责性能、输入生命周期和手机适配。游戏数值及美术仍由其他任务维护；共享工作区的全量测试结果以带时间的记录为准。

## 本轮修改

- 主循环限制为 60 Hz，逻辑保持固定 1/60 秒步长。90/120/144/165 Hz 屏幕不再按刷新率重复绘制；监测保留未截断的真实帧间隔。
- 暂停、帮助、构筑、结算界面停止重复绘制主战场；页面隐藏时取消主循环，回来重置时间基准，不补算后台时间。
- 加载完成再次同步画布尺寸，修复加载期间旋转手机后仍用旧画布尺寸的问题。旋转、暂停、切后台会丢弃未完成手势。
- 手机画布 DPR 上限 1.5、总像素上限 150 万，桌面总像素上限 300 万。仅调整画布内部像素，地图与命中坐标保持 CSS 坐标。
- 地图底图和河流遮罩按源图片共享；一次性像素读取使用独立小画布。河流中间纹理由 1600×1000 缩至 520×845，像素数减少 72.5%。
- 自然河流及水阵纹理每秒更新 30 次，主战场每秒合成 60 次。水阵复用已有地面画布，不再额外分配整幅纹理；强化、削弱、浓度变化立即刷新。撤阵、重开和释放场景会释放纹理。
- 绘制手势保留完整采样，每帧最多算一次闭合预览；放手仍即时计算实际落阵。三锋预览几何和暗角渐变复用。
- 手机横屏采用左右操作区，竖屏重新安排状态栏与操作区。主要操作目标至少 44 CSS 像素高，兼顾安全区；极矮横屏隐藏重复阶段文字，避免覆盖五行按钮。
- `mobile.css` 在主题样式之后加载，避免主题新增固定偏移覆盖手机安全区与按钮尺寸。

## 复测方法

正常页面不显示性能面板，URL 增加 `?perf=1` 后显示最近 300 个接受帧的 FPS、绘制频率、P95、CPU 分项耗时及 >34ms 帧数。CPU 绘制耗时只表示 JavaScript 提交时间，不代表完整 GPU 耗时。气运演示有自己的 30 Hz 循环，不计入主战场绘制频率。

`artifacts/performance/mobile.html` 是独立测试页，可在 390×844、844×390、320×568、667×375、568×320 之间旋转测试。将文件放在同源静态服务器根目录即可使用；本次隔离预览入口为 `http://127.0.0.1:5176/mobile-test.html`，避免其他任务构建覆盖测试中的文件。

本轮实测为 Windows 桌面浏览器、165 Hz 显示器、DPR 1.5 下的手机视口。没有真实手机、移动 GPU、发热降频或 iOS Safari 的验收结果。

- 五种视口下主要战斗按钮无越界，页面无横向溢出。气运/帮助/奖励列表可滚动，滚动区域中的屏外条目不能当作按钮越界缺陷。

- 加载中从竖屏切至 568×320，加载完成主画布为 852×480，修复前会残留 585×1266。
