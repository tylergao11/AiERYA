# 战斗划线与五行三态

2026-09-12。美术读取现有玩法的 `empowered`、`suppressed` 与 `reaction` / `invoke` 事件。状态改变材质、运动和阵纹，保留原多边形及结构位置；浓度是独立的强度输入。

| 五行 | 正常 | 减弱／受压制 | 增强 |
|---|---|---|---|
| 金 | 暗钢锋刃、短暂反光 | 锋光消退、刃体黯淡、灰屑散开 | 刃缘与刻纹亮起、阵内金纹流动 |
| 木 | 褐根、青叶、缓慢舒展 | 根叶失去光泽、枯叶落下 | 新叶抽出、枝叶摆动加强、灵力沿根汇聚 |
| 水 | 连续浅水与细水纹 | 灰青滞水、低波纹、泡沫减退 | 清晰波峰、较快水流与白色浪边 |
| 火 | 错峰火簇与焦土 | 保留灰烬、烟与冷却焦痕 | 翻卷加快、火簇增旺、局部地面受暖光 |
| 土 | 土脊连接不规则岩块 | 岩色暗淡、浮尘松散；土脊连续 | 土纹凝聚、沿土脊出现短促的受力亮纹 |

增强阵纹旁有小加号，减弱有短横刻痕，辅助辨识。耐久裂纹仍只读取真实生命值；土阵不会因压制表现而出现可通行的假缺口。当前玩法中压制会暂停阵法输出，因此受压制的火阵保留余烬与烟，不继续表现主动燃烧。若玩法以后改为部分削弱，再按新的有效强度调整。

## 划线的表现顺序

1. 按下并拖动：金是锋线、木是根笔、水是水带、火是炽痕、土是土脊笔触；末端提示绘制方向。轻薄底色按实际施法宽度投影，闭合笔迹提示内部作用区域。
2. 有效松手：沿实际笔迹即时显形，约 0.2 秒的方向脉冲掠过，材质在 0.3–0.9 秒内消散。粒子和短促地表痕迹服务于这一击。
3. 触发反应：相生显示向内汇聚，相克显示向外散开，受阻显示较暗的反馈。水克火在接触处产生蒸汽。阵法交会提示优先落到笔迹进入真实阵形的位置。
4. 持续状态：只有玩法实际设置计时的阵法才进入增强或减弱。一个笔迹可使不同阵法分别增强、减弱；`combo` 不会被当成全局强化信号。
5. 时间结束：读取实际状态恢复正常。水流用累积的材质时间调整速度，避免直接改倍速造成水纹位置跳变。

无效或灵力不足的释放不生成已施放特效。每笔最多 36 个材质装饰，密度由笔迹长度决定，不随指针事件数量增长。继续复用现有素材，无新增图片依赖。
