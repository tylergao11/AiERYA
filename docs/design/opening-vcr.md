# 水墨开场短片

2026-09-13。用户选定「水墨燃向：落笔成阵，五行爆发」。

## 成片

- 游戏资源：[opening-ink.mp4](../../public/video/opening-ink.mp4)。9.4 秒、1920×1080、30 fps，H.264 High / YUV420P / BT.709，AAC 双声道 48 kHz，已将索引前置以便边加载边播放。
- 镜头：宣纸落笔 → 墨迹揭开狼群与阵法师 → 金刃、木藤、水流、火势、浮石依次显形 → 五行阵纹冲击 → 「山野·阵火」书法片名落印。
- 形式为专门绘制底画与逐帧动画合成的水墨动效短片。摄像机、笔迹、五行图形、余烬、冲击波和片名均有动画；人物与狼采用绘画原姿态，未制作角色骨骼表演。
- 音轨为本项目程序合成的风声、擦笔、拨弦、鼓点与钟音，不含第三方音乐采样。最终音轨峰值约 -2.1 dBFS。

## 美术来源与重制

- 内置 image_gen 根据项目 `forest-valley.png` 与 `mage.png` 参考制作新的镜头底画，原有游戏美术未被替换。
- [底画](./visuals/opening/ink-battle.png)；[完整生成提示词](./visuals/opening/prompt.txt)。生成记录：`exec-c4ad7bfe-ef09-482e-a227-a8f853dd6d4e.png`。
- [逐帧渲染脚本](../../scripts/render-opening.mjs) 与 [配乐脚本](../../scripts/score-opening.mjs)；随机种子固定，便于复现。
- 渲染依赖 `@napi-rs/canvas`、FFmpeg、Windows 自带可用的华文行楷/楷体。字体只烘焙在画面内，未复制或分发字体文件。当前读取本机 Codex 已有画布依赖，没有给游戏增加运行依赖。
- 复现：`node scripts/render-opening.mjs`；只出关键帧：`node scripts/render-opening.mjs --stills`。换机器时可用 `CANVAS_MODULE` 指定画布模块入口，`FFMPEG` 指定编码器。

## 游戏接入

- `src/main.ts` 在加载场景美术的同时展示起始页；用户点击后播放短片，短片结束后才创建游戏界面、绘制输入与游戏声音。场景美术加载失败也不会提前撤掉起始页或中断影片。
- `src/ui/opening.ts` 管理短片的生命周期；`src/ui/opening.css` 只影响片头覆盖层。
- 默认停留在宣纸水墨渲染图；点击「入山」在同一个用户手势中调用入场音效与视频的 `play()`，视频从零开始带原声播放。移除「有声重播」。若此前保存了静音或零音量，点击入山会开启声音并恢复必要声道的默认音量。
- 封面采用内置图像生成工具，以影片真实首帧为参考制作，原图保存在 `docs/design/visuals/opening/opening-entry-ink.png`，运行资源为 `public/video/opening-entry-ink.webp`（1920×1080，约 275 KiB）。封面、首帧背景及视频全部使用相同的 contain 显示尺寸，保留宣纸与黑边。收到实际 `playing` 事件后，墨画封面在 520 ms 内淡出，直接露出纸上的画圈动画；减少动态效果时缩短到 120 ms。
- 入场音效 `public/audio/opening-enter.wav` 为已有 UI 音效的 0.18 秒片段，通过 `scripts/extract-opening-enter.mjs` 从现有音库提取并提高 14 dB（最终峰值约 −11 dBFS），保证点击反馈可听见；不新增音乐或更改影片音轨。
- 支持点击「跳过开场」和 Esc。播完/跳过进入原有五选二天命界面，不改抽取和战斗数值。
- 片头期间底层元素 inert；Tab 焦点限制在片头按钮。结束后恢复原状态，移除视频、计时器与事件监听。
- 手机竖屏完整保留 16:9 画面；按钮触控高度为 44 px，并留出安全区。
- 切后台暂停，返回继续。等待点击和等待播放重试时不计超时；影片真正开始后连续 8 秒前台无进度才放行。影片预加载失败时仍保留入山交互，点击后才进入游戏。系统开启「减少动态效果」仍保留用户主动播放。
