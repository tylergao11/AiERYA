# 封灵、受压与恢复

原表现只在宝宝栏写出异常状态，场上的灵体仍可能完成整段出手姿态。旧延迟发射只检查执行时是否沉默，短暂进入再离开沉默区后，旧蓄力仍有可能发射。本轮同时对齐状态、动作、指挥储量、镜头和声音。

## 实装规则

- `game/spirit-restrictions.ts` 提供同一份只读状态判断，供战斗、角色绘制和宝宝栏使用。绑定阵域不存在、被摧毁或受压时判为受压；否则按真实沉默区域判断。
- 战斗处理待执行攻击前刷新限制状态。限制生效时取消当前蓄力，并使该次延迟发射凭据失效；不会在解除后偷偷补发。保持正常冷却，不退还或消费尚未发射的御令。
- 已经发射的弹体仍遵守既有接触规则：到达时检查灵体、目标、射程、墙体与限制状态；不因新一轮蓄力的凭据失效而额外取消旧弹体。
- 沉默期间可执行撤离；绑定阵域受压仍服从原阵域约束。渲染不移动灵体，不改变状态持续时间，不赠送解除攻击。

## 画面与声音

- 封印收在实际龙口、鸟喙、鹿角、拳爪等出手部位。克制的灰紫封条表达“封”，阵域受压显示“压”；本体略淡，元素浮光降低。
- 停止被取消的完整出手姿态和蓄力粒子。御令储量继续保留显示，停止待发光点环绕，避免误读为正在释放。
- 解除后封条向两侧剥落，约 0.36 秒内恢复元素材质。换波、重置、移除灵体会清理状态画面，不在奖励面板关闭后补播解除。
- 合击特写的施法者在命中前被封灵时，镜头立即结束；其他同伴被封灵不抢断该镜头，已经命中的招式保留正常收尾。
- 增加短促收束声 `blocked` 和轻微上行恢复声 `freed`。真实状态变化才触发，各自用 0.4 秒全队间隔避免多宝宝叠响。暂停、静音、未解锁期间不积压事件。

音库现为 40 种音型、80 段切片、2,299,282 字节；峰值仍约 0.700。旧切片索引保持。单独对比音频：`artifacts/summon/summon-restriction-reel.wav`。
