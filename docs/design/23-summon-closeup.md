# 御灵特殊招式特写

- 同契合击：在真实蓄力/发射事件开始轻推镜头，覆盖施法宝宝、投射物与目标；正常约 0.94 秒完成推近、命中展示和回位。附近待命宝宝不扩大取景范围。
- 飞行期间保留轻推取景，真实命中后用 0.045 秒压实镜头，留出 0.16 秒命中展示再平滑回位。延迟命中会延后收尾；没有命中则从 1.15 秒开始回位，1.57 秒退出，避免镜头长期占用。
- 蓄力和飞行期间按施法者与目标的实际位置平滑修正取景；命中后保留真实落点，不追随受击狼的后续击退。远处同伴的晚到命中不会把镜头拖走，回响起手也不会触发特写。
- 祖兽吞势：满三层战意且持有强化御令时，在真实蓄力事件提前取景；真实重击确认后，镜头用 0.045 秒压近，保留 0.16 秒命中展示，约 0.62 秒内回位。蓄力不消费战意，也不提前触发重击笔锋。若旧印先杀死目标、战意失效等原因导致重击未发生，从 0.32 秒开始退场，0.74 秒内恢复全场。普通攻击、回响和非祖兽灵体不触发这段预取景。
- 祖兽蜕变：真实吞噬达到门槛时，给 1.18 秒聚灵与舒展特写，跟随祖兽本体；按成长后的尺寸计算取景。普通领悟、觉醒面板不自动抢镜头。
- 桌面最多放大到当前玩家视角的 1.48 倍，手机横屏最多 1.28 倍，手机竖屏最多 2 倍。竖屏以 0.18 秒推近并将主体与落点居中，横屏维持 0.11 秒。实际幅度按灵体和落点包围框缩小；使用玩家已有局部视窗时，按视窗可用空间取景，避免按整屏强行放大。
- 周边压暗，中心保留原色；命中瞬间在落点外围掠过六笔短促的元素笔锋，0.2 秒内散去，主体与伤害落点保持清楚。UI 保持原位置，游戏时间、伤害、攻击间隔均不变。
- 一道同契御令只拍一次；同伴的后续命中、追击、回响不重复开镜头。特写间隔至少 1.8 秒。
- 一局只发生一次的祖兽蜕变可覆盖正在进行的御灵短特写，并重新计算间隔；仍立即让位于划线、其他流派镜头、停时与波次切换。
- 划线起手立即结束特写，在第一个划线点取坐标前恢复正常镜头。召唤轻点另保留按下时特写中看见的狼或地面：即使回位后它已经不在手指下，仍指挥原目标；如果拖成划线则不使用这份暂存坐标。切换波次、停时、重置、手动缩放与窗口变化也会结束特写。
- 合击施法者在命中前被封灵或受压时退出特写；其他同伴受限不干扰当前取景，命中之后按正常招式收尾。
- 混合流派中让正在进行的斩击/阵法特写完成，避免同一帧抢镜头。系统减少动态效果时保留轻微压暗，关闭自动平移、缩放。

独立实现：`src/render/summon-closeup.ts`。入口与绘制接入 `src/render/view.ts`，使用同一个 `Camera2D` 保证投影与取点一致。
