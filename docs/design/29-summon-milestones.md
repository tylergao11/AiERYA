# 召唤成长与蜕变表现

真正的里程碑才播放成长演出。普通强化不再给全部宝宝重复发送“主灵觉醒”；初次出场保留独立出场表现，阵法化灵仍由原闭环阵法的消散负责。

`spiritTransition` 携带主灵 ID、变化前后体型和变化类型。首次觉醒、第二次突破、取得祖兽机缘、吞噬达到蜕变门槛分别触发一次。波次结束不清除里程碑记录；重新开局清除。原有吞噬门槛、体型倍率、伤害、费用和冷却不变。

1. 前 0.2 秒，灵气从身体四周收拢，保留原体型。
2. 随后 0.38 秒舒展到新体型，短暂照亮原插画本身，脚边铺开低矮的元素材质。
3. 碎石或元素细屑落散，1.18 秒内收干净。祖兽蜕变后的矿物游丝在待机、移动和攻击时均保留。

战斗中的祖兽蜕变使用 1.18 秒自动特写，手机横屏最多 1.28 倍、竖屏最多 2 倍，并按成长后轮廓和可用视窗缩小幅度。演出只调整绘制和镜头，不改变战斗时钟、碰撞或攻击进程。

吞灵过程由真实击杀驱动：本命祖兽击杀非召唤狼后，三缕断续的浅金灵息从倒下的位置加速收向兽口，宝宝栏同步显示吞灵进度。普通吞灵在接触后错开 0.1 秒出现，0.36 秒收拢；最后一份在 0.18 秒内入体，接续原有蜕变。进度仍在击杀结算时生效，不等待画面收集，也不增加伤害。最多保留八份吞灵表现，换波清空。

普通吞灵不触发特写，只有达到原有十二份门槛才推近镜头。进度条每次增加时轻亮，满后换为“已蜕变”；完成蜕变后停止收集。音效使用短促低沉的吸气和颗粒收束声，最后一份让位于蜕变出场音，避免叠响。

成长音效使用已加载的元素出场音，祖兽使用低沉的兽类材质，降低同时发生的普通攻击声音。奖励面板中产生的主灵觉醒音只保留最近一个，新增支援灵另按实体保留出场；在面板关闭且共享音频引擎真正恢复后播放，同材质合并。重置、静音、重新暂停、停时与退出相关阶段清除它们；锁定或暂停期间的战斗声音不补播。细节与真实挂起状态的验证见 `24-summon-audio.md`。
