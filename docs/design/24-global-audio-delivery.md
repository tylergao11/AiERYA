# 全局声音实现与验证

2026-09-13。本任务只负责全局音频与公共声音设置。各流派负责人继续拥有技能 UI、专属音色与触发设计。

## 实现

- `src/audio/mixer.ts`：一个实时 AudioContext，音乐、音效、环境三条独立通道；总音量、动态压缩与输出峰值保护。全局短音效最多同时 18 个，按优先级取舍；流派各自维护声音预算，共用音效通道与最终混音。
- `src/audio/score.ts`：96 秒原创主题、鼓、紧张弦乐共用音乐时钟。根据已发生的战斗压力平滑切换，包含迟滞和最短保持时间；狼王实际存在时进入高潮，奖励与结果阶段收束。不增加波次预告。
- `src/audio/forest-audio.ts`：狼群移动、撕咬、死亡、精英词缀、敌方读招及破招、分裂、营地受击、危险提示、修营、领悟与胜败声音。神速和巨化随实际跑动，狂暴只在进入状态时提示，再生需要生命确实增加，分裂需要幼狼确实生成。修营与领悟跟随成功的规则事件。
- `src/ui/audio-settings.ts` 与样式：总音量、音乐、音效、环境、静音及恢复默认。打开时暂停战斗并保留音乐，便于调音；关闭恢复原先的暂停状态。原有声音按钮保留为快捷静音。
- `src/audio/preferences.ts`：校验、保存与恢复本机偏好；存储不可用时仍正常运行。片头显式开关声音同步到局内偏好，自动静音播放不覆盖用户选择。
- `src/ui/audio.ts`：保留各流派负责人接入的专属声音，统一到公共音效通道与生命周期。

短音效避免静音、暂停与解锁前的历史事件补播。音乐与环境资源到达后按共同音乐时钟接入，某个资源失败不会拖住其他音轨。OGG 失败后尝试 MP3；最终失败后，后续用户交互可重试。销毁时停止声音、取消加载并关闭上下文。

全局解码使用独立的 24 kHz 离线上下文，实时输出保留设备采样率，避免解码时将全部音乐无谓扩容。实测全局素材常驻解码约 47 MB；此数字不包含各流派自行解码的声音库。

## 公共接入约定

各流派音色与事件归对应负责人管理。本任务提供：

- `mixer.onReady(callback)`：在实时上下文与公共通道就绪后接入声音。
- `mixer.buses.effects`：技能音效统一出口，遵循音效与总音量。
- `mixer.subscribe(callback)`：静音和音量设置变化；返回取消订阅函数。
- `mixer.duck(strength)`：有效重击时短暂降低音乐。内部限制触发频率，普通攻击不持续拉扯配乐。

全局控制器在流派爆发时只请求音乐避让，不重复播放技能音效。各负责人需要在暂停、重开与销毁时回收本流派的声音。

## 制作与体验检查边界

配乐试听为 `artifacts/audio/eastern-night-preview.wav`。来源、许可与重制命令见 [声音资源记录](../../public/audio/README.md)。

代码、自动化检查、编码分析和浏览器录制分别用于验证事件、稳定性、数值质量与实际输出。手机外放、不同耳机和用户个人听感尚未实测，不以帧率、波形或通过测试代替这些结论。
