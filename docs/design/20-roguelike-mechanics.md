# 肉鸽机制与杀伐操作验收

2026-09-13。用户将数值调优交给另一个任务，本任务负责机制、输入、交互和规则接入。本文不冻结伤害、耗灵、回复、概率权重、出怪与强度参数；这些继续由数值任务维护。

## 当前规则

阵法流后续专属重构见 [阵势完整机制与表现](./22-array-momentum.md)：独立阵势取代共享阵力，主放势保留通用成长联动，纯阵合鸣由开局天命归属判断。本文原有通用规则继续保留。

- 主角天生拥有五行。亲和只提供强化，不是元素使用权限。
- 开局五选二，可整批无限重抽。波间三项同池加权抽取，没有固定本命位置；待生效成长与转修机缘保留。旧稿的单命保底、暂存和固定主选位是历史方案。
- 纯杀伐构筑无法布阵。准备阶段的五行与撤阵操作置灰，显示「杀伐命格无法布阵」「迎战后可用」。开始迎战入口保留。点击、数字快捷键、画布按下与放置预览使用同一限制，不再画完才报错。
- 进入战斗后五行操作恢复。兼修布阵或召唤、局中获得相应机缘时，依照既有 `spellOnly` 规则允许布阵；重开不保留旧的禁用状态。
- 阵法一直自由绘制。古阵注灵身份沿用玩家几何，不使用点放、旋转或模式切换。
- 阵灵遵从 [当前确认的近远分工与化灵规则](./19-spirit-combat-and-ui.md)：木、土、祖兽近战；金、水、火远程。觉醒化灵后移除原阵；「阵中藏灵」允许共存。本任务不覆盖这套规则。

## 已接入的行为

| 内容 | 实际行为与边界 |
|---|---|
| 杀伐 | 三锋沿独立轨迹命中、旧痕交叉爆炸、借命透支、回锋重播、裂空；派生不会重新命令派生，回锋击杀可以触发一次追锋 |
| 五行基础反应 | 保留十种相生相克的实际控制、聚敌、消耗附着、熔金破防、固土护阵与连击；同一来源去重，独立接触与目标不会被整笔只取一个来源吞掉 |
| 五行轮转 | 不同相生关系积攒一次免耗；同类重复与派生不充数；无效笔画不消耗已获得的免耗 |
| 回澜地牢 | 金生水留下持续漩涡，泥沼敌人可触发一次缠足，尊重脱困免疫 |
| 沸雾还潮 | 水克火后留下湿雾，后来进入的敌人挂水，可以衔接新的反应 |
| 斩木飞刃 | 消耗根势后发出有限追加飞刃，不递归追锋 |
| 熔金剑藏 | 火克金存入有限剑数，后续非金手动施法消耗；不在取得当笔消耗，超时散去 |
| 五行阵灵 | 金沿弹道穿刺；木留下贴身根牢；水在命中处生涡聚敌挂水；火叠印爆炸；土近身践踏、削弱、修补邻墙 |
| 命中时机 | 近战接敌后命中；远程经历蓄势与弹道飞行。土墙和地形阻挡命中。落空、失去目标、被封灵时不虚增主灵能量、不白白消耗绝技 |
| 压制 | 阵法被压制后附属阵灵不能攻击；被封灵的火灵不能通过死亡火印继续爆炸。引灵失败不消耗共享阵力 |
| 精英反制 | 呼群、封灵区、狼王近身破阵均接入真实模拟与蓄力提示，相克命中可以打断；增援不递归召唤。数值任务正在扩展守御与猎灵等敌人行为 |
| 停时齐发 | 已接受的蓄笔及其有限派生全部释放，不静默丢弃后半段；界面显示蓄笔上限。具体上限从配置读取 |
| 反馈 | 领悟颜色按玩法分类；轮转免耗、藏剑与阵灵能量显示在构筑状态。划线显示实际成本，文本不再引用已删除的玩家施法冷却 |

## 实现与复核

- `src/game/world.ts` 的 `preparationLocked` 同时服务选系、输入及界面；`previewPlacement` 对纯杀伐返回命格限制，提交保持原有二次校验。
- `src/ui/interface.ts` 和 `src/ui/roguelike.css` 负责置灰与说明；`src/ui/input.ts` 在按下阶段阻止无效绘制，数字快捷键保持一致。
- `src/game/rogue-tactics.ts` 保存局内连招状态；`src/game/spirit-abilities.ts` 实现五系不同动作与实际生效检查；`src/game/rogue-combat.ts` 在实际命中时结算能量。
- 实现后另做测试与代码复核，未启动子 agent。没有修改其他任务的近远分工与化灵规则，也没有在用户移交数值后继续调参。
