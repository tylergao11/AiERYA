# 御灵指挥与接令反馈

本轮处理指挥过程中的两个问题：授令动画记录了下令时的固定位置，移动后的宝宝接不到画面中的灵光；快速换目标会堆积旧指令圆圈。正式运行时现在由 `summon-command-art.ts` 管理指挥表现。

## 视觉规则

- 点选敌人后，锁定印用 0.22 秒收拢。脚下分段印记留在地面，头顶箭形标记跟随真实跳跃高度，区分普通狼和大型狼的尺寸。
- 宝宝实际造成伤害时，印记短促收紧、提亮，0.16 秒恢复。持续伤害和其他目标的伤害不触发该反馈。
- 目标死亡后，头顶标记立即退场，地面印记在最后落点用 0.24 秒散去。换目标直接响应新的指挥；不保留多个旧目标圆圈。
- 授令光点在约 0.28 秒内汇向实际鹿角、鸟喙、龙口、剑锋、拳爪等出手锚点。每帧读取本体姿态和位置，到达后用对应五行材质收束；移除的灵体不留下悬空终点。
- 免费指挥只给宝宝短促的方向回应。付费授令仍可完成短途传递，画面最多保留四条近期指令，限制频繁输入的叠加。
- 集合点显示实际到位数量；全部独立灵体到齐后，记号减淡并显示驻守勾记。读取 `rallied()`，不会在绘制中调用寻路或制造到位状态。绑定古阵的灵体不计入自由集合队伍。

声音沿用实装的点选、集合、灌注音型和共享混音器，本轮没有新增音库或额外叠加提示音。玩法、伤害、御令容量、攻速、寻路保持原规则。

## 五行附着与出手衔接

持续御令由 `src/render/summon-armament.ts` 绘制，替换围着灵体旋转的三个菱形。金锋、藤叶、水带、火舌和岩片分别附在实际剑锋、鹿角、龙口、鸟喙、拳爪等出手位置，随本体移动、朝向和蓄力姿态更新。岩片之间保留空隙，避免遮住面部；材质沿用实装五行图集与火焰帧。

- 附着元素取实际御令，本命身体和近远分工不随授令变色或切换。
- 蓄力时附着收紧；近战真实接触、远程实际发射时短促释放。远程弹体落在敌人身上时，口部不会重复闪一次。
- 脚下储量按实际份数显示，半份不会画成一整份；最后一份消耗后留 0.16 秒释放收尾，随后退场。
- 只在剩余储量全部将过期时减淡附着；不因新的御令刷新旧储量期限。合击就绪和已经授出的合击分开显示。
- 封灵或受压时压低附着、停止蓄力与喷发；波次切换、重置、移除灵体及销毁绘制器时清理。减少动态效果时关闭流动、呼吸与释放拖线。
- 所有显示读取真实状态，绘制不消费御令、不结算伤害，也不新增音效事件。

`artifacts/visual-review/summon-armament-review.html` 提供六种本命、五种御令及受令、蓄力、释放、用尽、将散、封灵、满共鸣和合击待发的定点案例。使用真实御令接口和接触结算，位移与攻击时间由短脚本安排，不运行对局。

2026-09-13：附着、授令、灵体锚点及限制状态共四个文件、28 项定向检查通过，生产构建通过。浏览器核对石卫附焰、祖兽转向、储量归零退场、水龙岩甲和受限显示。证据：`artifacts/visual-review/summon-armament-spent.png`、`summon-armament-water-earth.png`。不据此推断整局平衡或手机硬件性能。

## 停时蓄令：笔画入灵，接敌兑现

原先纯召唤停时释放沿用了普通法术的粗光带、全屏闪白与震屏，画面像笔画当场杀伤，但实装只给宝宝储令。现由 `src/render/summon-storm.ts` 提供召唤专属演出：保留五行细笔，释放后收束为短促灵流，汇入实际出手锚点；重击与震屏留到真正攻击命中。

- 以实际储量增加和新合击凭据产生接收效果；满容量的多余笔画不制造假灌注，失去实体的接收点立即消失。各笔原有元素保留，收尾只在每个宝宝上合成一次材质回应。
- 停时期间暂时收起纯召唤宝宝栏，恢复后显示真实余量。横屏标题避开顶栏；竖屏标题置于实际战场内的下方，避免落到顶部留边后被界面遮住。
- 文案说明「御令按容量入灵」「接敌后依次释放」。空放显示未蓄御令，不宣称一次齐发命中。
- 召唤与杀伐、阵师混搭仍使用其原有停时演出与伤害路径；本轮只替换不直接施法的召唤停时。未修改伤害、攻速、容量、过期或收费参数。
- 聚灵声音合并为一次受令回应，普通停时解除声压低；入灵阶段不播放命中音和震屏。减少动态效果时省去移动灵流，保留静态接收与文字。

预览 `artifacts/visual-review/summon-storm-review.html` 使用真实停时、御令与伤害结算，三灵固定站位，攻击时刻由短脚本安排。`World.tick` 只在停时本身激活时调用，恢复后不运行战斗 AI 或整局模拟。

2026-09-13：八项新增停时检查连同召唤音频、授令、公共音频与 UI，共五个文件、68 项通过，生产构建通过。浏览器的三笔案例：入灵后每灵 9.87 份、目标实扣 0、战斗时钟 0；近战接触后主灵 8.87 份、目标实扣 17.5；远程到达后各灵 8.87 份、目标实扣 26.9。这里验证结算衔接，不宣称该固定案例证明完整对局平衡。手机界面证据为 `summon-storm-portrait.png`、`summon-storm-landscape.png`。
