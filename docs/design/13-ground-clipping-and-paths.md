# 有效阵域裁切与自然寻路

更新：2026-09-12。空地按用户标出的林间地面向右侧和下方扩展；保留自然寻路，不设置强制中央路线，不显示狼群路线虚线或空地辅助边线。

## 贴边布阵

- 近似闭合后，将笔画与可用地面求交。林外、河流、山石、营地和角色占用部分自动排除，不因局部越界拒绝整笔。
- 绿色预览与最终阵法共用同一裁切结果。多个有效片区和片区内部的空洞都会保留，不用凸包把空地缺口填平。
- 多个片区仍是一座阵，只收一次灵力、占一个阵位、触发一次成阵扩展；攻击间隔、生命和撤阵也按整座阵计算。
- 浓度按裁切后所有片区的有效面积计算；土阵按实际轮廓总长计算。小于最小有效面积的碎片不成阵，完全没有有效地面时不扣灵力。
- 重叠限制按实际有效区域的交集面积计算，保留少量重叠容错，狭长阵和分离片区也不能重复堆叠。
- 主轮廓继续保存在 `points`，完整地形保存在 `regions`：每个片区第一条是外轮廓，其余是排除的孔洞。成阵扩展收到包含完整轮廓的独立只读快照。

## 封路与行进

土墙覆盖裁切后的整个有效阵域，能够接到林地边缘或河岸；裁切不会额外往里挪出一条可绕过的缝。普通狼和狼王在没有开放绕路时停下破墙，墙被破坏后重新寻路。当前精英狼另有跃障能力，但必须跳出整块实心墙体后才能落地。实体土墙细则见 `15-solid-earth-wall.md`。

无遮挡时直接沿连续方向前往营地，取消空地上由八方向网格产生的大折线。有地形或土墙阻挡时再使用寻路场。火、水、木、金阵不作为避让障碍，狼不会因为伤害区域而自动绕开它们。

直达检测使用整个移动线段的体积碰撞：对轮廓线段、岩石和土墙检查狼身体的间距，长距离视线不再每帧密集采样。避让同伴、普通攻击和精英跃障仍由各自的移动模块负责。

## 验证

`tests/edge-placement.test.ts` 覆盖新增右侧、左侧和下方地面、原输入截断位置、大幅越界裁切、分离片区、孔洞、成阵扩展快照、浓度面积、一次扣费与撤回、各片区实际伤害、普通狼与狼王封路破墙、三处入口无遮挡直行。

`tests/combat-balance.test.ts` 的阵位跟随真实直线路径调整，继续使用真实波次、灵力和调息进行三波防守对照。`tests/wolves.test.ts`、`tests/wolf-vault.test.ts` 继续验证身体碰撞、攻击与精英跃障。

本轮完整测试 210 项通过，TypeScript 检查和 Vite 构建通过。浏览器已验证越界土阵自动裁切、实际轮廓显示及无辅助线的场景；固定预览包中狼群在土墙前停下并交战，没有从贴边封口穿过，营地安危保持 100。

几何布尔运算使用 [polygon-clipping](https://github.com/mfogel/polygon-clipping) 0.15.7；地面裁切由 `ground-clipping.ts` 统一处理，模拟和渲染通过 `ward-geometry.ts` 读取有效轮廓。
