# 阵法流：五行辅助与阵势

## 当前规则：五行地形辅助（2026-09-13）

本节覆盖下方早期版本：阵中藏灵、古阵化灵、移动阵眼、阵灵共养阵势均已删除。阵法开局、成阵、觉醒、升华都不会生成召唤单位。古阵始终留在手绘位置，保留原几何、耐久、预算和阵势。

核心循环：**相生起辅 → 留敌养势 → 相生传势 → 相克放势 → 辅阵续接。**

主角仍具有全部五行；通用强化和独立召唤流保留。混修御灵可以召唤御灵单位，但阵法天命不再激活召唤奖励，异流派奖励仍可作为留待机缘的干扰项。

### 五行辅助

正向相生划过阵眼激活辅助。每座阵每 2.5 秒至多激活一次，基础持续 3 秒；最低 20% 标准投入，短笔缩短持续与效力。空阵不触发攻击辅助，受损阵可用土辅修护。

| 五行 | 实际效果 | 连招用途 |
| --- | --- | --- |
| 金 · 裂甲开锋 | 标准投入使阵内目标额外承伤 22% | 为后续阵法、法术和混修攻击创造窗口 |
| 木 · 缠枝留敌 | 本次辅助对每敌束缚一次，服从控制免疫 | 留怪接灼烧、蒸汽或斩木 |
| 水 · 聚流牵引 | 持续向阵眼聚敌，挂水并减速 | 集中目标，位移仍遵守碰撞 |
| 火 · 续燃传火 | 已燃目标续燃一次，最多加 1.5 秒；首次向阵内至多两敌传播 40% 火种 | 延续已有火势，再接水克火；不凭空点燃空场 |
| 土 · 固阵护持 | 修复原阵 3.5% 最大耐久，降低原阵损耗与受击 25%，弱化阵内敌人攻击 25% | 保住阵地；与公共护阵取较高减伤，不乘叠 |

辅助没有普攻，不直接造成伤害。火种传播沿用终结火种，不递归蓄势；每个目标每次最多续燃一次，不缩短已有长灼烧。阵被撤除、摧毁则辅助消失；封灵停止辅助刷新，波末与重开清理。

## 玩法闭环

每座自由绘制的阵都有自己的阵势，真实有效伤害积累，不自然增长。战斗中划过阵眼，按笔画方向连接相生阵，传递七成储备并记住沿途五行。先结算整条传递，再放势，避免起点提前释放截断连锁。同一座阵每笔只访问一次。

同系划线放出本系招式；相克划线改为五种转化招式。必须有实际可命中的敌人。短笔按真实投入限制本次可花阵势，重复提交同一张施法凭据不重复结算。阵势跨波保留，换局、撤阵与销毁清理对应状态。

入门组合：水阵有效命中养势，划过水、木、火三座阵；水生木、木生火传势后，用水克火触发蒸汽破阵。只有两阵也能完成传势和本系放势。选择五行回环后，会自动沿附近相生阵多走一站；回环引阵再增加一站。

| 五行 | 本系放势 | 相克转化 |
| --- | --- | --- |
| 金 | 万刃穿阵：指向附近敌人的窄线穿刺 | 金克木：消耗根缚，斩木飞刃 |
| 木 | 千根缚杀：伤害和定身，尊重脱困免疫 | 木克土：碎岩根牢、打断 |
| 水 | 归墟引潮：聚敌，留下短暂水涡 | 水克火：熄火，蒸汽破阵 |
| 火 | 焚阵燎原：爆发、灼烧 | 火克金：熔金开锋、暴露弱点 |
| 土 | 镇岳震关：震退、削弱敌人、修补附近土墙 | 土克水：截流泥牢、持续减速 |

经过的五行会给终点招式附带聚敌、束缚、破防、余火或震退。集齐五印是长线构筑目标。升华「周天合鸣」后，带五印的主放势在 0.8 秒内按水木火土金追加五式，每式使用本次已消耗阵势的 20%；追加招式不再积势或派生。

## 开局身份与六张成长

- **五行回环**：开局双古阵，传势自动寻找下一座相生阵。
- **阵中藏灵**：保留原阵与附属阵灵，实际伤害共养所属阵势。
- **移山换阵**：迁移保留阵势，落点有敌时释放本系技能；失败落点不收费、不放势。
- **纯阵合鸣**：开局所选天命全属阵法时，主放势可带动附近另一座至少有 20 阵势的阵，各付各的储备，每笔至多额外一阵。后续拿通用或跨流派成长，不追溯修改已选天命。

| 成长 | 在循环中的作用 |
| --- | --- |
| 留势刻印 | 主放势留下已花阵势的 24%，接下一轮；不改变基础阵强度 |
| 回环引阵 | 自动再传一站；不改变公共攻速 |
| 破势余阵 | 留下本系短暂场地效果，帮助下一批敌人进入连招 |
| 三才回响 | 三种以上印记让主放势在原位追加 42% 回响 |
| 借尸续阵 | 主放势击杀留下至多三个阵痕，7 秒内再划线引爆 |
| 借敌行阵 | 有效攻击花 6 势给敌人附印，它进入另一座相关阵时送势或小型放势 |

六项均为一次性机制选择。依然参与同一个随机奖励池，保留干扰项、待用成长与转修机缘，不保底送齐一套。

## 通用边界

- 五行基础能力、灵力价格与收入、十种基础反应和通用奖励，继续使用公共系统。
- 主放势可触发已有五行成长，例如金系击杀追锋；用独立 `arrayRelease` 标记阻止反向给自身蓄势。合鸣、回响、阵痕和余阵为终结效果，不无限递归。
- 保留已确认的阵灵近远分工和实际命中检查。觉醒后古阵化灵、原阵退场；阵中藏灵允许共存。阵势按原阵 ID 随阵灵继承，阵眼随阵灵移动。
- 阵法与召唤混修时，划线继续执行御令，同时允许经过阵眼传势放势。没有改回纯召唤的直接划线攻击。
- 压制、封灵、死亡、无目标、阵法移除都会限制对应释放；自己的相克转化在本笔共同反应结算后仍能完成。

与现有杀伐特写共用 Camera2D，混修同次触发时由杀伐镜头优先，阵法不会重置其变换。新划线在第一个坐标换算前恢复普通视角；缩放、旋转屏幕、暂停、切阶段和停时也会取消特写。减少动态效果模式保持镜头静止，仅保留轻微聚焦明暗。修复正常松手后的 lostpointercapture 误取消新特写的问题，仅丢失仍在进行的手势时才取消。
