# 御灵动作与发射点

## 土系左右腿交替：纠正上一轮遗漏

上一轮对步频和镜像的修复没有解决图集本身的问题：石卫四张步行图均保留近侧右脚领先，缺少远侧左脚越过右脚的动作。技术检查通过不代表左右腿画对。后续生成的八帧候选也重复了这个错误，未接入项目。

石卫改用 `earth-gait.ts`：从原插画按石板关节缓存身体、大腿、小腿、脚掌，左右腿各自保留髋、膝、踝和脚点，固定近远遮挡关系。右腿先支撑，左腿抬起越过；半周期后左脚在前，改为左腿支撑、右腿迈过。支撑脚不随整个身体的步行弹跳离地，土系的脚尘位置直接读取这两只脚的实际落点。原出生位置、攻击时机和伤害不变。

逐帧核对页 `/artifacts/visual-review/earth-feet-review.html` 展示四个关键相位及连续动作，标明左右脚。新版已接入实际 `SpiritArt`。新增检查直接验证两脚前后关系交换、支撑腿交换、腿段连接和脚尘对应；与姿态、步频、脚步相关共 32 项通过。仅做短动作核对，不跑整局。

## 右侧出生与步态抖动修复

营地伴灵改为在右侧空地错位出生，主灵、双生和觉醒增援之间保留空间；位置被占或有土墙时先在右侧寻找可站立点。阵法化灵仍从自己的阵法位置出现。

修复表现帧和固定逻辑帧不同步时的误停步：旧逻辑把每个没有位移的表现帧当作停止，会额外推进收脚；固定 60 Hz 位移、120 Hz 绘制的两秒复现中，步态相位从正常 8.69 错增到 23.97。现在保留 85 毫秒停步确认，只按实际路程推进步态。纵向移动的细小横向修正不再触发镜像翻转，真正横向转身依据平滑速度判断。

石卫与灵鹿蓄势时保留行走本体，出手时短暂过渡至接触动作，恢复后回到原本体；按落脚锚点统一接触图比例，修复土系切换动作时突然缩小的问题。嘴、鹿角和拳部的特效发射点跟随同一过渡。

`/artifacts/visual-review/summon-motion-review.html` 使用实际出生和移动组件，提供石卫、灵鹿、祖兽的出生、左右行走、纵向行走、停步及攻击衔接短预览，可暂停和逐帧查看，不运行整局。出生、步态、脚步、姿态、御令附着、近远战与输入相关 70 项检查通过，生产构建通过。

## 已修正的问题

旧近战动作在伤害发生时才开始前冲，身体最强姿态落后于命中。现在前段蓄势，蓄力结束前完成出手，真实接触时保持约 45 毫秒的动作重心，再在原恢复时间内收回。伤害、攻击间隔、移动与碰撞规则不变。

`SpiritPoses` 读取真实 `spiritAttack` 的蓄力、发射、接触事件；御令额外部分先击杀目标时也能对齐接触。回响不重新启动本体攻击。改变命令清除原施法时，动作结束，不带着未完成的挥击撤退。

- 出手期间保持朝向，避免目标穿过身体时突然左右翻转。
- 转身时平滑移动身体支点，并轻微收窄轮廓，减少整张贴图换面产生的跳动。
- 步态沿实际移动距离推进；近战落脚经过步态的着地点时才扬起轻尘，尘迹留在原地并沿实际移动的反方向散去。飞行灵体随移动轻微倾斜，不产生脚步尘。
- 五行的发射点分别按剑锋、鹿角、龙口、鸟喙、拳部校准，祖兽沿原拳爪锚点随姿态变化。蓄力光每帧跟随身体；已发射的弹体保留发射时的位置。
- 回响的透明度乘算保持到命中绘制，避免后续绘制覆盖透明度设置。
- 首次出场按本体材质区分：剑灵从短刃光中收拢，灵鹿随根叶舒展，水龙沿两股水流升起，凤凰从余烬间下落；石卫与祖兽落地后压低重心、再站稳。轻微伸缩与位移同样作用于嘴、爪和脚点，不让出场中的发射点留在旧位置。
- 出场身体在约 0.42 秒内到位，碎屑在 0.64 秒内收净，石卫与祖兽的落地拍位在 0.19 秒。表现不推迟实际攻击、不额外生成震屏或伤害范围。阵法化灵保留原有 0.26 秒衔接，普通强化不重播出场。
- 群灵站位按插画高度判断遮挡，火鸟、水龙等飞行灵体平滑错开；只改变绘制偏移，最多 84 插画像素，近战脚点保持不动。发射点、阴影和授令锚点随本体一起移动，特写取景为此预留空间。密集队伍仍允许部分重叠，不强行改动寻路或碰撞。
- 授令的飞行终点也使用每帧更新的出手锚点，不再固定在下令时的旧坐标；详见 `32-summon-command-feedback.md`。
- 落脚的碎叶、砂砾与爪尘各有重量；最多保留十六个尘迹，每个 0.36 秒退场。停止移动只收回抬起的脚，不反复生成新尘；瞬移与攻击也不冒充步行。移动音效使用同一个落脚回调，详情见 `24-summon-audio.md`。

## 文件与预览

实现位于 `src/render/spirit-pose.ts`、`spirit-art.ts`、`spirit-presence.ts`、`spirit-vfx.ts` 和 `rogue.ts`。角色本体沿用现有插画及四帧步态，不将程序形状替代插画。

`spirit-footfalls.ts` 管理有界的落脚尘迹，`SpiritPoses.update` 提供按距离推进的落脚回调。`spiritStep` 只向表现与声音传达接触，不参与游戏位移或伤害。

`/artifacts/visual-review/summon-effects.html` 增加“移动与转身”模式；元素和模式保存在预览 URL，热更新后仍可继续查看同一种灵体。资源就绪前禁用选择按钮，避免早期点击丢失。

可用 `?element=water&frame=1.42` 查看龙口蓄力定格，用 `?element=beast&frame=1.51` 查看祖兽接触帧。定格只重放表现事件，未运行战斗模拟。正常预览不带 `frame` 参数。
