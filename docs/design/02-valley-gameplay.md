# 森林阵法塔防：当前玩法

更新：2026-09-12。本文件按用户最新确认统一规则；旧的独立五行储量、环境取材和战斗手动切换模式已废弃。

## 核心循环

玩家拥有五行灵根，全部五行共用灵力。布局时在空地围拢成阵；战斗时选择元素划动施法，闭合画圈同样有效，按瞬时范围攻击结算。既有阵法持续防守，战斗灵力自然恢复。每波结束选领悟，返回布局调整，再迎接下一波。

## 当前已实现

- 默认初始灵力 100，每阵 14，战斗每秒恢复 6，每次划动消耗 8，全局间隔 0.65 秒。
- 首尾接近自动闭合，修正轻微抖动和收笔交叉，允许少量重叠与地形微调。失败不扣资源，绿色预览使用最终可成立的轮廓。
- 同样投入，大阵覆盖广且浓度低，小阵浓度高。金木水火按实际面积分摊，土按墙长分摊生命。无额外面积收费或旧面积上限。
- 持续阵法负责自动伤害和控制；土墙承担阻挡与可破坏防线，移除后同步恢复寻路。
- 五行主动作用：金直接伤害、木束缚、水减速推流、火灼烧、土震退。
- 完整相生链：木→火→土→金→水→木；相克链：木→土→水→火→金→木。
- 主动划动与敌人附着、沿途环境、已有阵法发生反应，产生增益或额外伤害。无需接触环境也可以直接施法。
- 相生强化被生的元素及其阵法/宝宝；木生火助燃，火生土修复土墙；相克己方阵法引发对敌爆发并压制其攻击 2 秒，不扣生命。反向遭到克制的主动法术会削弱。
- 当前三波狼群进攻营地，营地生命耗尽则失败，三波守住则胜利。波间营地恢复 15。

## 已有扩展边界

成阵通过纯规划接口生成附加持续单位描述，由 World 一次性创建、分配身份和结算。宝宝归属于实际阵法轮廓，使用该阵浓度与预算，撤阵、土墙被毁和重开同步清理。当前没有启用默认宝宝种类。

后续可扩展狼群行为、特殊技能、肉鸽成长与单位内容。当前不扩张角色自由移动、自由挖掘、无限火灾蔓延或全局物理模拟。
