# 森林露营 · 环境与阵法塔防玩法

> 更新：2026-09-12。以 [设计总纲](./01-core.md) 中的最新情境为准。
> 当前处于设计讨论阶段。下面明确区分已确认原则与候选规则，不包含已经废弃的效果或实现方案。

## 1. 已确认的玩法骨架

1. 玩家是一名年轻的五行阵法师，在森林露营途中遭遇狼群攻击。
2. 金、木、水、火、土的灵力来自场景中的环境资源，玩家就地取材抵挡进攻。
3. 阵法承担塔防中的持续攻击、防守与控制，布阵会改变地形及其战斗用途。
4. 布阵沿用已确认的闭合原则：线闭合后才能形成持续阵域，未闭合不留下持续区域效果。
5. 作战时额外使用划线能力，与天然环境和已被布阵改变的地形产生作用。
6. 划线是主动干预手段，持续防守应由已经成立的阵法承担。

“进入阵域即可引动”继续作为已讨论过的交互方式；天然地形也必须能够参与战斗划线，完整反应规则需要在新资源体系下定义。

## 2. 角色、营地与敌人

### 年轻阵法师

五行灵根使角色能够利用五种环境力量。角色是否可自由移动、是否需要靠近资源、采集是否占用战斗时间，目前未定。

角色的视觉身份应明确，不宜在设计过程中默认为一个不存在于场景中的控制光标。可见角色的具体操作和受击规则仍需讨论。

### 临时营地

篝火是已确认的火资源。露营设施的构成以及被攻击后损坏的方式尚未确定。

胜负需要明确守护对象：阵法师、篝火或整个营地。没有确定之前，不自行添加多条血量、燃料倒计时或额外失败条件。

### 狼群

基础敌人采用狼。体态、奔跑和咬击先建立真实威胁，再讨论是否加入不同类型。

敌人的接近方向、数量、波次、选路、攻击目标，以及能否破坏某种阵法地形，都属于玩法规则。绕行、追击和群体配合可以作为候选，不自动视为已经确认。

## 3. 环境取材

| 环境资源 | 对应灵力 | 需要在场景中看清的内容 |
|---|---|---|
| 树木、植物与森林环境 | 木 | 能提供木灵力的对象、与普通背景植被的区别 |
| 河流等自然水体 | 水 | 水源、岸线、流向和可利用位置 |
| 沙地、土质地面 | 土 | 可利用地表，以及与岩壁、道路等位置的关系 |
| 场景中的金属资源 | 金 | 可信的资源来源及其外观；具体物件尚未确定 |
| 篝火等现场火源 | 火 | 火源位置、状态和与周围环境的联系 |

### 待决定的取材规则

- 通过接近、点击、划线连通，还是把资源纳入阵图取得灵力？
- 五行灵力分别储存，还是通过环境连接决定可用属性？
- 取材消耗资源、暂时削弱资源，还是只借用其力量？能否恢复？
- 灵力获取有无距离、容量和时间限制？战斗中是否可以继续取材？
- 当某种资源不足时，玩家有哪些明确的应对办法？

这些问题决定地图布局和节奏，应先于阵法伤害数值定稿。不能把五行都做成与场景无关、开局随时可用的技能按钮。

## 4. 布阵如何改变地形

已确认：闭合布阵建立持续阵域，阵法具有持续战斗作用，并改变场地的状态或用途。

一个阵法的设计需要完整回答：

| 问题 | 必须给出的定义 |
|---|---|
| 从哪里取得力量 | 资源类型、取材条件和消耗 |
| 在哪里成立 | 可布阵地形、闭合要求、范围及资源关系 |
| 地形发生什么变化 | 几何结构、通行、地表状态或元素性质的变化 |
| 如何持续防守 | 自动攻击、防护或控制的方式、目标与节奏 |
| 如何被主动利用 | 战斗划线与它产生什么额外作用 |
| 如何结束 | 解除、耗尽、破坏或恢复时地形如何处理 |

地形改变不能只表现为一个彩色圈。例如隆起的土障应当与通行判定一致，出现的水流应具有对应流向，缠绕地带应与实际控制区域一致。

### 用于讨论的五行方向

下表仅用于说明环境、阵法与主动能力的联系，**不是已锁定的技能配方**。

| 元素 | 候选布阵改变 | 候选持续防守 | 候选主动划线作用 |
|---|---|---|---|
| 木 | 让根系与藤蔓在阵地内生长 | 缠绕或周期性牵制经过的狼 | 收紧根网、延伸一段藤蔓或集中牵制 |
| 水 | 利用水源形成浅流、湿地或水路 | 持续减速或水流冲击 | 沿选定方向集中推流 |
| 土 | 抬升土脊、改变沙土地面 | 阻挡或改变狼的路线 | 定向震动、局部崩落或短暂开口 |
| 金 | 利用金属资源建立攻击节点或锋刃结构 | 周期性打击进入范围的狼 | 让攻击沿划线方向集中释放 |
| 火 | 利用篝火建立具有可见热源的火阵 | 持续或周期性灼烧 | 集中爆燃、沿满足条件的路径传递火势 |

可以从中挑选适合场景的方向，也可以替换。最终需要一套有限、易懂且有辨识度的规则，不因拥有五行就自动扩张为完整组合矩阵。

## 5. 战斗划线与环境反应

划线经过的是一个有状态的战场。需要识别：沿途天然地形、可取材资源、已成立阵法以及已经被改变的地面。

### 已确认的区别

- 天然地形可以与划线产生额外效果。
- 布阵改变过的地形也可以与划线产生额外效果。
- 形成持续阵域依赖闭合布阵；普通未闭合战斗线本身不自动变成持续阵域。
- 单次主动释放的表现与阵法长期运作的表现要能区分。

### 候选交互例子

| 当时的环境 | 可能的主动作用 | 需要先定义的边界 |
|---|---|---|
| 河流或已引出的浅流 | 让水沿划线方向形成一次推进 | 是否能离开河床、作用长度和推力范围 |
| 天然树林边缘或已有根网 | 激活沿途根系，形成一次牵制 | 哪些植物可响应，是否留下长期地形变化 |
| 沙地或已经隆起的土障 | 激起一段地面震动或使局部土障变化 | 可通行性何时改变，结束后是否恢复 |
| 金属资源或阵法攻击节点 | 集中一次定向攻击 | 需要哪些连接条件、路径是否能穿障碍 |
| 篝火、火阵或可响应的带火地面 | 释放一次方向清楚的火势或爆燃 | 可燃对象、传播条件、是否影响营地和树林 |

这些例子用于讨论，不意味着默认允许无限蔓延的森林火灾、自由造河或任意破坏地形。

### 每条定稿反应必须写全

触发对象 → 需要的灵力与环境状态 → 划线方向或顺序条件 → 攻击/控制结果 → 地形状态改变 → 持续与结束 → 资源代价。

同时明确：预览如何提示、失败为何失败、一笔内重复经过怎样处理、多个区域连续经过时怎样结算。不能用特效画面反推规则。

## 6. 地形状态与规则一致性

同一处场地可以具有自然基础与布阵后的改变。设计上需要区分：

- **自然基础**：地形高度、材质、水流、植物、金属资源与初始通行性。
- **阵法改变**：由布阵建立的结构或状态，以及持续作用。
- **主动反应**：战斗划线触发的瞬时作用或有期限的改变。

一处改变涉及多个系统时，画面、寻路、落笔、资源和后续技能应使用一致结果。修改结束后如何恢复需要明确，不能出现画面已经恢复而狼仍被空气墙挡住的情况。

为了理解成本和性能，第一轮优先考虑可定义、可预览、可恢复的局部地形变化。是否需要自由挖掘或完整物理模拟尚未确定。

## 7. 塔防节奏：待讨论

体验应包含观察环境、临时布防、抵挡进攻和应对局势变化，但尚未锁定阶段限制。

- 开战前有多少准备时间？
- 取材、布阵与额外划线能否在战斗中同时进行？
- 敌群按波次进攻，还是连续逼近并留出短暂空隙？
- 防线被突破后，玩家可以撤阵、补阵、移动或退守吗？
- 一局的目标时长与结束条件是什么？

先确定以上节奏，再定义敌人刷新、波间安排与成长内容。

## 8. 需要优先确认的四个问题

1. **取材方式**：玩家怎样从森林、水流、沙地、金属和篝火取得力量？
2. **角色与守护目标**：阵法师是否移动，狼最终攻击谁，什么情况失败？
3. **第一套具体阵法**：选一个元素，把资源、闭合、地形改变、持续防守和主动反应从头讲通。
4. **布阵时机**：准备与战斗怎样衔接，战斗中是否能够重新布阵？

先明确这四项，再确定地图资源数量、阵域限制、作用距离、持续时间和伤害数值。

## 9. 后续玩法验收范围

- 可以看懂每种力量从环境哪里取得。
- 合法闭合布阵与未闭合线的结果不同，反馈及时且准确。
- 阵法在没有持续手动划线时仍能承担塔防作用。
- 布阵改变地形后，狼的移动与后续技能响应符合规则。
- 天然地形和已改造地形都存在明确、有价值的主动交互。
- 玩家可以预判至少一条划线的效果，结果和视觉提示一致。
- 阵法结束、被破坏或重新布置时，状态和地形正确收尾。
- 正式流程的胜负、输入和资源规则完整，具体标准随上述未定项定稿后补齐。
