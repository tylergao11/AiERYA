# 五行战斗反应：蓄势、转化与连招

2026-09-12。用户要求其余相生相克也形成好玩的实际战斗操作。本轮在已有灵力浓度、主动调息和水火蒸汽规则上执行。

## 战术设计

相生保留并强化来源，准备持续收益；相克把已有元素转成另一种效果，改变敌人站位、控制或受伤方式。五行仍共用 100 灵力，恢复 3/秒、主动 12/笔，阵法承担持续防守。

| 关系 | 玩法 | 当前数值与限制 |
|---|---|---|
| 木生火 · 助燃蔓延 | 延续灼烧，并把火种传给邻敌 | 原火效果乘 1.35；蔓延到半径 3.2 内至多两只未燃烧敌人，各获源灼烧的一半预算并乘助燃倍率，持续 1.5 秒；不递归传播 |
| 火生土 · 固土护阵 | 修墙、临时护墙，同时压低敌人扑咬伤害 | 墙回复最大生命 20%；强化期减伤 35%。交汇点附近至多六只敌人受镇压 4 秒，基础攻击下降 30%，浓度放大后最高 50% |
| 土生金 · 凝锋连击 | 把一次主动投入变成接下来几轮的追击 | 金阵强化期存三次追击，命中后再打半径 3.2 内另一只敌人，伤害为本击的 50%；无邻敌不消耗次数，4 秒后未用次数消失。敌人附着或天然源交汇可给一个目标留下同样的有限连击标记 |
| 金生水 · 聚流漩涡 | 把分散的敌人聚拢，配合火阵、蒸汽与泥沼 | 半径 3.2 内最多六只；拉力有上限，不能累加速度或穿墙。水阵强化后脉冲会继续轻微向阵心聚敌 |
| 水生木 · 滋养缠枝 | 缠绕向旁边两只敌人传递，接续留敌 | 基础缠绕 0.85 秒，受浓度影响，上限 1.5 秒；不刷新已有束缚，不跳过脱困免疫，无自动递归扩散 |
| 木克土 · 破土生根 | 碎岩打击并缠足，守住突破口 | 交汇点半径 3.2 内最多六只，基础 12 伤与 0.85 秒缠绕；土阵反击暂停 2 秒，墙体和生命保留 |
| 土克水 · 截流泥沼 | 消耗水势形成短暂泥沼，后来的敌人也受影响 | 半径 3.2、持续 4 秒，基础减速 65%、上限 80%；移出后约 0.35 秒解除。最多三片，每笔至多一片，附近重施替换旧区；不是持续阵法，不产生宝宝 |
| 水克火 · 蒸汽爆炸 | 删除当前灼烧，换一次范围爆炸 | 继续已有规则：半径 3.2，同次重叠取最强伤害，不叠加，不自动连锁；火阵保留并可重新点燃 |
| 火克金 · 熔金破防 | 先制造破绽，再让阵法集火精英与狼王 | 交汇点最多六只，基础 6 点熔击，4 秒内承受额外 25% 伤害；浓度放大后最高 40%。弱破防不覆盖或续时强破防，不指数叠加 |
| 金克木 · 斩木碎裂 | 主动结束一个目标的缠绕，换重击和木屑溅射 | 基础 12 + 剩余束缚秒数 × 12，束缚最多计 1.5 秒；溅射一只邻敌，伤害为重击的 40%。每笔只转换一个主目标，其他直接命中的狼保留原缠绕；木阵蓄势也能提供基础碎裂，不凭空获得额外束缚时间 |

相生的先后顺序不改变“被生者”：木划火与火划木都形成火效果。相克只在正向转化；逆向受克仍是本次直伤 65%，不偷偷附加有利反应。

## 可尝试的连招

- **聚流 → 泥沼 → 火阵**：金划水把敌人拉在一起，再用土把水势转成较宽的滞留区，接住后续狼群。
- **缠绕 → 斩木**：木阵留下敌人，金划线提前结束一个目标的束缚换爆发；是否放弃剩余控制由玩家决定。
- **助燃 → 蒸汽**：让木强化火势并传播火种，再用水把剩余灼烧兑现为爆炸。也可以继续留火，省下灵力等待下一群。
- **熔金 → 凝锋集火**：先破防，再依靠金阵或金划线输出；破防会放大所有后续有效伤害，而不是只改显示数字。
- **固土救险**：被狼围住的土墙可以用火修复并护墙，给其他阵法争取时间。

## 消耗、顺序与边界

每笔先读取接触前的源强度、灼烧和束缚，正常命中后再执行有限的附加效果。同一关系每笔选择一处最强交汇点，同强度优先实际敌人附着；不沿整条涂画重复创建同一种范围效果。不同关系可以在一笔中共同出现。

相克消耗来源阵的蓄势，至少恢复 50% 才能再次转化。火阵正常运作并用 4 秒回满；其余相克先暂停攻击 2 秒，再按 4 秒回满。相生可以唤醒阵法，但不会凭空补回被消耗的蓄势。没有额外五行灵力池。

实际燃烧、束缚和潮湿会参与反应选择，后来的附着标签不会抹掉仍有效的状态。火优先处理水/木；真实缠绕可供金/水作用；真实潮湿可供土/金/木作用。泥沼没有水附着，不能靠泥沼自己反复生产泥沼。

新增跟随攻击走独立伤害入口，不能再触发跟随攻击；一个普通金命中最多引出一次凝锋追击。阵法与目标同时有储存时也不发双重追击。蔓延火种只有主动交汇时传播，平时燃烧不会再次传播。

大圈和长线仍按原有笔画范围预算稀释附加伤害、控制强度和拉力；源阵浓度参与转化。破防和镇压有上限，控制继续尊重脱困和受击保护。灵力不足、冷却未结束、错误阶段不会产生反应。

## 反馈与扩展

操作说明中列出全部十种关系；选择元素时，页脚给出该元素的三种组合提示。泥沼显示真实有效区域；聚流显示向内旋纹；连击、火种、缠枝显示来源与目标连接；破防、镇压和剩余连击次数可见。页脚“反应”统计蒸汽和其他反应的有效伤害，继续排除过量伤害。

`src/game/reactions.ts` 集中参数、请求、临时区域和有限的跟随效果；`reactionEffect` 事件提供效果类别、交汇点、半径和目标位置，方便美术替换表现。模拟不依赖特效时长，肉鸽成阵和宝宝接口继续保留。

## 验证

`tests/reaction-tactics.test.ts` 覆盖十种关系中的新增战术：实际移动、扑咬减伤、土墙承伤、有限连击、场外蔓延、后来入场的泥沼目标、破防对后续伤害的影响、束缚消耗、弱状态不续强状态、浓度稀释、重复请求上限、暂停和重开。

`tests/combat-balance.test.ts` 用真实波次和合法灵力/调息操作进行对照。当前战术脚本三波击退 48 只、营地 100：阵法约 2799.4、主动约 591.0、蒸汽及其余反应约 1034.5 有效伤害。使用了聚流、泥沼、蒸汽、连击、破防和斩木。只划金仍在第一波失守。此结果验证连招可以实际完成战斗，不代表所有布局与操作均已达到最终平衡。

运行 `npm test` 与 `npm run build`；输出对照可用 `npx vitest run tests/combat-balance.test.ts --disableConsoleIntercept` 查看。

本轮验证结果：185 项测试通过，TypeScript 与 Vite 构建通过。浏览器通过实际鼠标绘制五座阵法，验证了凝锋的独立追击伤害和剩余次数、聚流的向内拉拢、泥沼的有效区域、固土护阵提示及十种反应的可滚动操作说明；浏览器错误日志为空。三波对照已在最终代码上复跑，结果与上文一致。
