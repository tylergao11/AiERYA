# 五行合击：展开、接触和消散

保留已有插画，拆开统一的放大淡出。所有画面从实际 `summonImpact` 开始，不另加伤害、命中、控制、范围或隐形延迟。

| 御令 | 合击动作 | 主音型 |
| --- | --- | --- |
| 金 | 短促刃弧与三道错开的锋线，快速退成火星 | 三次间隔约 45 毫秒的刃鸣，短尾音 |
| 木 | 根须从地面抬升后收紧，叶片翻落 | 木质重击、接续枝裂 |
| 水 | 浪形抬起再向落点回卷，水滴内收 | 第一记浪拍、后段回流和滴落 |
| 火 | 焰羽展开，主焰提前退场，留下流动小火与余烬 | 爆燃、短二段火响、火裂尾音 |
| 土 | 岩柱抬升后下沉，碎岩带阴影落地 | 岩击、随后散落的石粒 |
| 祖兽 | 各种御令都保留与身体朝向一致的三道爪痕 | 兽喉、撕裂及沉重着地，保留御令材质层 |

持续时间约 0.54–0.86 秒，各自不同。地面材质与大幅主插画画在角色下方，刃线、接触碎屑与爪痕留在前方，保证近战宝宝和狼的轮廓可见。同一目标、同一元素在 0.3 秒内紧邻命中的合击保留一个完整主效果，其余接触缩为 0.28 秒；回响使用 0.36 秒的较淡材质，不重复展开大招。不同目标、不同元素和相隔较远的命中仍独立绘制。全队一次御令的主音只出现一次，最多 8 声部。

`src/render/summon-impact-art.ts` 仅负责合击材质动作；普通强化、指挥、受令和机制领悟仍由原有画面负责。`src/audio/summon-bank.ts` 在离线生成时区分六种音型，游戏中不生成波形。吞势和同契同时出现时，同契使用更高声音优先级并压低吞势声部。

预览 `/artifacts/visual-review/summon-union-review.html` 可切换五行、祖兽、祖兽携水令；各有命中、展开、消散、落稳定帧和手机横竖屏。播放模式可在画面内开启声音。页面使用实装绘制与声音，只驱动美术时钟，不运行对局。

验证：召唤音效、实际接触归属、特写与共享音频四组共 48 项检查通过，生产构建通过。资源共 76 段、2,239,756 字节，峰值约 0.700，旧切片偏移保持。此轮不验证整局数值，也不将波形检查等同于主观听感验收。

浏览器逐项查看五行展开与火焰消散、祖兽携水令的爪击；截图在 `artifacts/visual-review/summon-union-{metal,wood,water,earth,beast-water}.png`。新版音库在浏览器显示“音库就绪”，实际播放计数随原生攻击、强化和同契循环增加，静音操作可用。
