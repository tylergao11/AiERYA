# 五行本命技能的画面与声音

御令强化覆盖在本命能力之上。本轮让玩家看懂宝宝自身擅长什么，保持原本的攻击距离、伤害、间隔、三印阈值与场地半径。

| 灵体 | 可见案例 | 实际来源 |
| --- | --- | --- |
| 金 | 剑锋击中前狼，短促剑痕连接后方实际穿中的两狼 | 原生穿刺扣血后发送命中位置；射程外、偏离弹道者不画命中 |
| 木 | 脚下树根生长并收紧，被真正缠住的狼脚边出现根须 | 读取真实根牢、已触及目标与 rooted 状态；离开根牢或主人消失即失效 |
| 水 | 命中处出现地表漩涡，泡沫与水丝向内移动，前沿掠过狼脚 | 读取真实水涡的中心、半径和余时；沉默/阵域压制时降低亮度并停止流动 |
| 火 | 狼身上三枚火羽逐一亮起，三印或死亡时向上爆燃并散出火星 | 读取真实火印层数；爆燃使用独立事件，取消原先重复普通圆圈和长文字 |
| 土 | 近身落脚震出裂纹和碎石，邻敌受击；贴墙修补沿用实际修补反馈 | 原生践踏结算后发送事件，不能在远处仅播放震地来冒充命中 |

地表原画为 `public/art/spirit-ground-atlas-v2.png`，两列三帧，共用一张 1024×1536 素材，约 2.11 MB。共享资源优化现已切换加载同名 `.webp`，实际文件存在、约 1.39 MB；保留 PNG 原画。木根跨帧生长，水涡跨帧混合、缓转与向内流线共同运动；只在绘制时变化，不延长技能寿命。黑底用 screen 混合，下面铺克制的土色/水深阴影。没有读取或修改每帧像素。

火印徽记按镜头缩放补偿，避免手机上缩成不可辨认的点；消耗第三羽时会短闪对应羽数。额外命中特效上限 32 个，按招式寿命清除；换波、重开、销毁清理。所有声音复用既有混音器和 8 声部上限；新穿刺、燃爆、碎石音色详见 24 号文档。

实图检查发现石卫的 heavy 标记被误当成祖兽爪击。现新增独立 ancestor 标记：石卫仍是重击，却不再绘制爪痕；只有实际祖兽保留爪击形状。正式事件与祖兽预览同时接入，并覆盖石卫/祖兽两种回归。

短招式预览：`/artifacts/visual-review/summon-native.html`。五个按钮分别展示本命动作、实际技能结算与对应表现，可开启音效。预览只手动推进图像/状态余时，并调用单次技能及其即时场地接触；不运行 World.tick、完整 RogueCombat.tick、寻路或波次对局。

本轮最终验证：生产构建通过；`spirit-abilities-feedback`、`summon-audio`、`summon-contact`、`global-audio`、`spirit-art` 五个测试文件共 44 项通过。五行技能的定向命中、爆燃不递归、有效目标归属、受压/过期/主人消失与不改变仿真状态均有检查。浏览器分别检查金、木、水、火、土的实际命中画面以及音库解码播放；可用“定格招式”重看动作。截图为 `artifacts/visual-review/summon-native-{metal,wood,water,fireburst,earth}.png`，火印两层另有 `summon-native-fire-brand.png`。验证不能替代完整战役平衡或手机真机性能结论。

此前镜头轮属于有效进展：已修改正式取景与命中归属代码，并取得构建、定向检查及手机尺寸截图。本轮继续补本命能力的表现，整体召唤流目标仍需结合未完成的战役数值验证与实际体验验收，未标记完成。
