# 插画 UI、转场与资源交付记录

2026-09-13。当前视觉以 `visuals/warm-scroll-v2/build-concept.png` 的整幅暖色卷轴为基准。此前深蓝面板、纸笺贴在深蓝底上的组合不再作为新页面基准。

## 统一规则

- 窗口本体是一幅完整画卷：纸面承载内容，书法标题退入纸面安全区，铜轴与纸边只作装饰。
- 朱砂笔触承担主要确认操作；铜扣承担关闭、重播与工具入口。次要操作使用纸面墨字。
- 流派同时通过大字、完整名称、专属插画和颜色识别：杀伐朱砂、布阵古金、召唤苍玉。混合构筑显示两套标识。
- 主战场左右的空余区域使用独立朱砂山纹插画；不会截取主背景来延长。边界不参与投影与选点。
- 手机点击卡片预览，点击「选定」确认。详情通过点击展开。选择反馈不改变手牌基线；重复教程和重抽解释不常显。

窗口由 `PanelSurface` 管理打开、退出、背景输入隔离、焦点恢复和详情滚动位置。普通窗口进入 220 ms，开局与奖励进入 300 ms，退出 180 ms；系统减少动态效果设置会停用这些动效。调音独立原生 dialog，返回保留暂停菜单。

入场手记接在视频完成事件之后、首次 UI 渲染之前。每次从开场进入都默认展示基础页，不受旧版「已看过手记」记录影响；切换章节保留「开始修行」按钮。此时尚未选取命格，因此基础页展示通用规则，关闭手记后继续原有天赋选择，不代选、不提前开始战斗。局内手动查看仍使用「返回」。

本次入场改动验证：`common-ui`、`ui-assets`、`opening` 共 24 项通过，`npm run build` 通过。在 956 × 440 浏览器横屏中完成视频跳过、正式构建自然播完、看过后重新进入、换章后继续、右上角关闭、选满两项入山及局内手动打开／返回的实际点击检查。证据保存在 `artifacts/visual-review/entry-handbook/`；这些检查属于浏览器验证，不代替手机真机测试。

## 尺寸与性能

目标设备的物理横屏为 **2868 × 1320**，依据 [Apple iPhone 17 Pro Max 技术规格](https://support.apple.com/zh-cn/125091)。页面主设计尺寸为 **956 × 440 CSS px**。

- 浏览器验证 956 × 440、1280 × 720、440 × 956。安全区测试额外模拟左右各 62 px、底部 21 px，未把模拟值写成真机常量。
- 主游戏仍使用真实 `env(safe-area-inset-*)`；旋转时重新计算画布与布局。横屏五个天赋选择目标约 47 px 高，主要按钮至少 44 px。
- `canvasResolution` 限制手机画布倍率至 1.5，且限制总像素预算；956 × 440、设备倍率 3 时画布为 1434 × 660，DOM 字体仍按设备原生分辨率绘制。
- 正式游戏 `?perf` 的一次活动战斗采样：60.0 FPS、绘制 60.0 FPS、P95 18.3 ms；平均逻辑 1.61 ms、绘制 1.21 ms、UI 0.05 ms，300 个样本中无超过 34 ms 的帧。证据 `warm-performance-battle.png`。
- 打开菜单后战斗停算、场景停止重复绘制；背景标签停止帧循环。演示采用独立节流、共享已解码资源。

上述属于桌面浏览器尺寸模拟与本机性能数据，**没有 iPhone 真机实测证据**，不将其解释为真机恒定 60 帧承诺。

## 图片与视频资源

- 新插画由内置 `image_gen` 生成，PNG 原图、精确提示词和图集映射保存在 `visuals/warm-scroll-v2/`。`asset-prompts.json`、`boundary-prompt.json` 保留生成依据。
- 朱砂边界原图实际左右外侧各三分之一是插画，中央留白不用于主战场延展；运行时分别绘制两侧图集单元。
- `python scripts/optimize-art.py` 从保留的原始 PNG 生成 WebP；`--check` 校验来源 SHA-256、产物 SHA-256、尺寸，以及无损图集的 alpha 和可见像素。清单 `runtime-art-manifest.json` 记录 18 个文件。
- 18 幅来源合计 41,972,061 字节，运行版 17,977,616 字节。角色、狼、阵法等图集使用无损 WebP；大幅背景与 UI 使用质量 92。没有修改原图像素尺寸。
- 场景资源与 UI 各采用最多三个解码任务，重复请求复用同一个 Promise；字体和菜单图提前准备，避免首次点击现解码。
- 字体使用 OFL 授权 Ma Shan Zheng 子集，当前 332,020 字节、862 字符；新增文案后运行 `scripts/subset-ui-font.py`。
- 开场优化版 `public/video/opening-ink-mobile.mp4` 保持 1920 × 1080、282 帧、9.4 秒，AAC 音轨直接复制；H.264、yuv420p、faststart。7,374,547 → 4,820,172 字节，对原版 SSIM 0.992688。命令见 `video-optimization.json`。
- Vite 发布流程保留运行资源并排除已有 WebP 对应的 13 张源 PNG（27,178,132 字节）及原版开场视频。原始文件继续留在仓库。每次发布检查所有 18 项运行图片均存在。
