# 杀伐：原地蓄力、即时划斩与招式构筑

本文件是杀伐当前实现基准，覆盖此前聚势、锋威的纯数值奖励。杀伐的玩法、数值、UI、刀光、打击声与震屏由同一模块交付；阵师与御灵由其他负责人维护。

## 操作与投入

**2026-09-13 用户确认：普通划动即时触发；杀伐原地按住蓄力，蓄好后划出去重斩。** 按住时不扣灵，开始有意划动时锁定蓄力时间；每帧只结算尚未释放的新路径，第一段用蓄力档位，之后继续划动接快刀。已经结算的路径在松手时不再重复。取消、切换五行、暂停、后台、波次结束丢弃未释放部分，不撤销已经发生的攻击与扣费。屏幕位移 4 像素以内作为杀伐持笔容差；原地松手不放空刀。召唤点按指挥、迁阵松手确认及停时整笔暂存保留。

| 持续时间 | 档位 | 追加灵力（统一标准单价 3） | 实际刀宽 |
| --- | --- | --- | --- |
| 不满 0.4 秒 | 轻划 | 0 | 1 倍 |
| 0.4 秒 | 蓄势 | 1.2 | 1.15 倍 |
| 0.8 秒 | 重斩 | 2.7 | 1.4 倍 |
| 1.2 秒 | 破军 | 4.8 | 1.75 倍 |

四单位长的基础笔画投入 3 灵力，满蓄投入 7.8，伤害随标准投入变为 2.6 倍。0.4 单位短划只需 0.3 灵力；满蓄短划也必须付出额外 4.8 灵力。价格统一读取 ECONOMY.strokePrice，后续整体经济调整不改变档位和标准投入的倍率。图形浓度仍约束超大圈的伤害。资源不足时按可支付档位释放；基础笔画本身也付不起则不释放。免费大招保留蓄力，但不能生成免费刀势。

## 快刀到重斩的循环

- 杀伐默认战斗自然回灵为 3 点/秒；灵力硬上限为 100，自然回灵、击杀收入和笔画返还均不能超出。
- 一笔对所有实际命中目标分别结算。标准及以上投入，每个目标计一次连斩；不足标准投入按比例积累，显示整数部分。派生、回锋和宝宝不重复计数。
- 连斩窗口 3.2 秒，极短笔画只能续上同比例的窗口。达到 8 / 20 / 40 连斩进入连斩、疾风、无双，提升表现强度，不直接无限叠伤。
- 有实付的快刀（轻划或蓄势）按投入积攒刀势，命中三敌时达到该笔 25% 的积势效率，上限 1.2 笔标准投入。重斩/破军消耗刀势，最多追加自身投入的 50%；空挥也会消耗。
- 杀伐每只普通原生狼基础回灵 0.75 点；原生精英为 3 点、狼王为 18.75 点，沿用全局四倍/二十五倍倍率。AOE 多杀逐只回灵，不受单笔返还额度限制。侧锋、回锋、刀痕、持续伤害、相克与停时大招击杀同样回灵；通用「归元」和「逆脉」按比例修改这项收入。援狼不回灵，同一具尸体不能重复结算。
- 基础回灵之外，付费斩击保留有限额的额外返还：所有派生共享一张实付账单，至多实付的 60%，并受返还天赋上限约束。基础回灵和额外返还合并成一次事件，HUD 显示实际到账总额，光点从倒下的狼飞回角色。免费大招只领基础击杀收入，能在灵力归零时补灵；未击杀时不凭空恢复。

续航示例：3 灵力释放标准快刀击杀一只普通狼，到账 0.75 + 1.8，余额 2.55；再用一单位短划花费 0.75 补掉另一只残血狼，到账 0.75 + 0.45，余额回到 3。群杀可以盈利，单只残血适合短划，不保证每个击杀都无条件填满一记重斩。HUD 和余额保留两位小数，避免把 0.75 显示成 0.8；可用灵力不足 8 时提示短划补刀，狂书待发时仍优先提示 2.2 秒接刀。

## 成长奖励改为实际招式

| 旧 ID / 新名称 | 操作衔接 | 升级收益 |
| --- | --- | --- |
| slayer-edge / 游刃先手 | 有效快刀攒先手，下一刀原地蓄力时提前入档，重斩消耗先手 | 每标准投入攒 0.1 / 0.15 / 0.2 秒，上限 0.3 / 0.45 / 0.6 秒；手势至少持续 0.18 秒才计入 |
| slayer-return / 回锋纳气 | 重斩命中留下 2.8 秒回锋印，下一刀与印交叉时逆向追加一次回锋 | 50 / 65 / 80% 回锋，按新一笔实际投入折算；保留有限击杀回灵 |
| slayer-focus / 断岳追破 | 满蓄命中留下 3 秒破绽，下一笔付费快刀追击并消费破绽 | 对该目标追加本笔 30 / 45 / 60% 威力；可一刀追破多敌 |

三锋走多线清群、先手转重斩；刀痕走横留纵切、引爆接回锋；借命狂书走重斩借势、快刀追斩。觉醒回锋和升华裂空保留，并共享付费笔画的上限，不能递归出招。其他流派的待用奖励不会直接给杀伐加成。

借命狂书：付费满蓄实际命中后保存上一刀投入的 30%，持续 2.2 秒；下一笔付费快刀消费这份力道，追加量最多为该快刀自身投入的 60%。两者取小，因此微划不能白拿一整记重斩。预览和支付失败不消费，实际空挥会消费；派生斩、免费大招和空重斩不能造出下一次追斩。旧有透支至 -36 灵力、负灵力下 60% 威力加成保留。UI 显示接刀倒计时，追斩有铜色副刃和较重的斩声。

## 纯杀伐成套：千锋归一

判定**本局实际选下的流派天赋**。出生选择和途中机缘必须只含杀伐；选到阵师/御灵成长（包括暂未激活的流派成长）会打破成套。通用、五行、相生相克强化不打破。

刀势至少 0.5（总刀势容量的约 42%，HUD 的合技进度已蓄满）时，满蓄重斩实付并命中，90 毫秒后在命中中心追加一道垂直交叉斩：长 9 单位，45% 威力，沿线全部目标生效。只触发一次，不重新积刀势、蓄先手、造回锋印或再出交叉斩。混修保留基础连斩和蓄力。

锋甲狼对杀伐金刃保留 98% 抗性，且完整锋甲不被金刃打出僵直；侧锋、回锋和交叉斩同样受制。火破防后解除。其他法术维持原有护甲规则，真实阵法伤害规则不变。弹刀有独立钢色偏折、音效及「换火破甲」提示。

## 表现与性能

原地持笔时光点收拢，三段进度环显示可用蓄力。划动时立即使用五行各自色彩的实线刀光；重斩加宽亮芯、切口和碎光。回锋印画在原刀路上；破绽用敌人身上的裂口标记；纯杀伐追加交叉刀光。伤害数字来自实际伤害事件。

杀伐状态栏显示 Combo、连斩数、刀势、先手、一刀多杀、回锋与纯杀伐身份；构筑页和帮助页解释实际接招方式。手机版错开构筑按钮和五行操作栏。
