# 战斗灵气、五行反应与绘制容错

更新：2026-09-12。按用户本轮要求：删除借灵，五行共用灵力；战斗随时间恢复，五行改为划动触发，画圈仍可操作；手绘差不多围拢即可。

## 阶段与灵力

| 阶段 | 输入结果 | 灵力 |
|---|---|---|
| 布局 prepare | 近似闭合创建持续阵法，可触发肉鸽成阵接口 | 每阵默认 14，有限预算，不自然恢复 |
| 战斗 battle | 所选五行沿线施法；近似闭合则覆盖圈内，不新增持续阵或宝宝 | 每笔 12，自动恢复 3/秒 |
| 波间 rest | 选择领悟，营地回复 15 安危，再进入布局 | 保留剩余灵力，不自动补满 |
| 胜负结算 | 停止操作 | 不恢复；重开重置到初始值 |

初始灵力与容量均为 100。五行全部可选，没有单元素储量、资源按钮、采集冷却或 Q/E 模式切换。全局施法间隔 0.7 秒，并有各行独立调息；无效输入、间隔未结束、灵力不足不扣费、不命中。撤阵仅限布局，返还实际投入的一半并向下取整。

恢复由模拟时间计算：`min(容量 - 当前值, 每秒恢复 × dt)`。暂停、帮助界面和页面隐藏期间不推进模拟，不离线补发。恢复修饰使用 `Stat.regen`，技能消耗使用 `Stat.castCost`。澄心增加恢复速度 35%，不增加布局池。

汲取表现采用每秒合并的 `spiritRecovered` 事件，环境微光汇入阵法师，同时统一灵力条增长；满池停止汲取反馈。音效不按每秒自动重复播放。

## 五行主动效果

| 五行 | 划动的基础结果 | 相生方向 | 相克方向 |
|---|---|---|---|
| 金 | 锋刃直接伤害 | 金生水 | 金克木 |
| 木 | 伤害与束缚 | 木生火 | 木克土 |
| 水 | 伤害、减速与定向推流 | 水生木 | 水克火 |
| 火 | 直接伤害与持续灼烧 | 火生土 | 火克金 |
| 土 | 伤害与定向震退 | 土生金 | 土克水 |

无须先碰环境也能施法。天然林木、溪水、沙地、铁器、篝火和已成立阵法仍作为元素交互对象。每笔只结算一次施法、一次扣费，每只狼最多一次本笔直接伤害，来回涂画不能重复收取命中。

普通划动影响距线段 1.5 单位以内的敌人；近似闭合还影响圈内敌人。修正后的闭环决定真实作用区域，凹形缺口保留。主动数值独立存放在 `SPELLS`，不再乘用阵法伤害。金 16 伤、2.4 秒调息、最多两只且第二只减半；木 2 伤、4 秒；水 2 伤、3 秒；火 4 伤、3 秒；土 5 伤、4.5 秒。其余四行最多四个直接目标。主动木基础束缚 0.6 秒，主动水减速 30% 持续 1.4 秒，主动火灼烧每秒 3 点持续 1.2 秒。来回切换元素不能绕过该行调息，画圈也不能绕过目标上限。

为保持有限灵力预算，范围倍率为：闭合时 `16 / max(16, 实际面积)`，未闭合时 `16 / max(16, 划动长度)`。范围倍率同时影响直伤和状态强度；极小手势不会无限放大。布局阵法仍使用单独的 [灵力浓度规则](./06-spirit-concentration.md)。

## 反应结算

狼记录最后一次元素附着，持续 5 秒；普通阵法、宝宝与主动施法都可留下附着。下一次主动命中先读取旧附着，再按有方向的反应确定结果元素。水或木碰到仍在燃烧的敌人时，实际燃烧优先于后来覆盖的附着标签。默认自动攻击负责铺设元素，主动划动负责主动反应。

| 条件 | 结果 |
|---|---|
| 所选五行与旧附着或沿途环境/阵法构成相生 | 本次直伤乘 1.5，状态强度乘 1.35，结果使用被生的元素；多处相生不继续叠乘 |
| 当前所选五行克旧附着或沿途环境元素（水火例外） | 额外增加 0.75 份基础直伤；多处相克不重复累计 |
| 当前所选五行生划过的己方阵法或自然元素源 | 该源强化 4 秒，解除之前的压制；阵法及宝宝伤害/状态强度乘 1.35，再次施放刷新时间 |
| 火生土墙 | 在强化之外回复其最大生命 20%，不超过浓度决定的最大生命 |
| 当前所选五行克划过的己方阵法（水火例外） | 消耗源阵蓄势，在接触处触发破土、泥沼、破防或碎裂；阵法及宝宝暂停攻击 2 秒，清除强化，不扣阵法生命 |
| 当前所选五行克自然元素源（水火例外） | 消耗源蓄势并触发对应战术效果，压制其元素反应 2 秒，清除强化 |
| 沿途环境或旧附着克当前所选五行 | 本次直伤降为 65%，不覆盖既有附着、不附加当前法术的控制或灼烧 |

克制火时清除爆炸范围内的灼烧；斩木每笔只转换一个主目标的束缚，其他直接命中的狼保留缠绕；截流清除交汇点附近目标原有的潮湿减速，再由泥沼独立留敌。木生火的结果保持火附着，施加更强的灼烧，不替换为木束缚；连续助燃使用固定倍率，不指数叠加。

原通用相克阵域爆发已替换为各不相同的战术效果，见 [五行战术反应](./11-elemental-tactics.md)。每笔每种关系选择一处最强交汇点，读接触前浓度并乘本笔范围倍率；范围反应最多六个目标，不递归重复命中。压制期间或源蓄势不足 50% 时不能重复抽取转化。所有来源强度在本笔修改状态之前快照，避免当笔强化再当笔读取造成自我放大。

场景与阵法来源按本笔是否接触判定，无须苛刻规定一笔内先后顺序。多个环境来源冲突时，使用接触前强度最高的一个决定沿线反应，同强度按固定五行顺序处理；敌人自身的有效反应优先。各个被划过的阵法分别受到强化、压制或消耗蓄势；附加战术效果按每笔每种关系的上限执行。

相生除统一强化以外，还提供火种蔓延、固土保护、有限连击、聚流和缠枝；相克提供独立的元素转化。具体参数、目标上限与连招见 [当前完整设计](./11-elemental-tactics.md)。

## 两个基础例子与完整反应名称

**水划火：消耗灼烧，换一次范围蒸汽爆炸。** 删除该次灼烧，敌人不再继续吃这次持续伤害。以直接命中的燃烧敌人为中心，爆炸伤害为 `8 + 剩余燃烧秒数 × 当前每秒灼烧`；半径 3.2 单位，会打到划线外的邻近敌人。

划过火阵也可消耗热量，在实际接触处爆炸：基础 28 × 阵法浓度 × 强化倍率 × 当前热量；自然火源基础 16。热量初始 100%，消耗后归零，战斗中 4 秒回满，至少 50% 才能再次抽取。火阵、火宝宝继续攻击，可以重新点燃；原有灼烧和火场热量分别消耗。

同次划水的每个目标只承受覆盖自己的最强爆炸一次，不叠加所有重叠爆炸，不连锁引爆旁观敌人。爆炸范围内清除灼烧，伤害同时受当前笔画范围倍率稀释。不再额外叠加旧版水克火 0.75 份直伤。爆炸结算读取接触前快照；由 `steam` 事件表现白闪、范围扩散圈和蒸汽伤害数字。没有燃烧也没有可用火场热量时，不会凭一个旧火附着标签制造爆炸。

**木划火：木生火。** 给火助燃。火阵及其宝宝强化 4 秒，输出乘 1.35；对仍在燃烧的敌人，结果仍为火，灼烧增强，重复助燃不无限叠乘。表现为火势变旺和“助燃”提示。

| 关系 | 名称 | 受益或受克对象 |
|---|---|---|
| 木生火 | 助燃蔓延 | 强化火势，火种传给两只未燃烧邻敌 |
| 火生土 | 固土护阵 | 修复土墙、临时护墙并降低附近敌人的扑咬伤害 |
| 土生金 | 凝锋连击 | 储存三次追击，命中后攻击另一只邻敌 |
| 金生水 | 聚流漩涡 | 把附近敌人向交汇点拉拢，配合范围输出 |
| 水生木 | 滋养缠枝 | 缠绕传给两只邻敌，尊重脱困免疫 |
| 木克土 | 破土生根 | 碎岩伤害与缠足；土阵反击暂歇，墙体保留 |
| 土克水 | 截流泥沼 | 消耗水势，留下四秒泥沼，后来踏入的敌人也减速 |
| 水克火 | 蒸汽冲击 | 消耗灼烧/火场热量，换一次范围爆炸；保留火阵 |
| 火克金 | 熔金破防 | 熔击并附加四秒破防，提高后续有效伤害 |
| 金克木 | 斩木碎裂 | 转换一个目标的剩余缠绕换重击，木屑溅射一只邻敌 |

同元素没有额外反应。相生的结果始终是被生者：木划火与火划木都生成火效果，但消耗和基础攻击仍来自当前所选法术；相克有强弱方向，火划水会受克削弱。

自然元素当前每种对应一个来源状态；强化/压制仅限战斗模拟时间，不改变原地图的通行轮廓。重开清空状态，波间冻结剩余时间。土墙压制暂停其攻击，不删除墙体或凭空改变生命。

## 手绘容错

1. 首尾距离允许 `clamp(包围盒对角线 × 0.4, 2.5, 6)`，同时要求画出的线长至少为缺口的两倍，避免把普通直划误认成圈。
2. 小幅抖动先简化；收笔过头、自交回环保留面积更大的主圈，不把所有轮廓变成凸包或标准圆。
3. 轮廓越过地图边界、河流、山石、营地或角色占用区时，自动裁掉无效部分，保留所有有效片区及孔洞。完全没有有效地面才拒绝，不向内挪出绕墙缝隙。
4. 两阵轻微相交允许成立；任一阵约超过 25% 的面积被重叠才拒绝。比例按有效轮廓的实际交集面积计算。
5. 不再因圈内含营地或障碍直接拒绝；轮廓和默认阵内锚点仍须合法。场地很窄处不能强行包围营地。
6. 有效面积至少 0.01，最多六座阵。无额外面积上限，绘制仍受真实地图边界限制。

预览与提交共享同一套纯规划函数，绿色预览显示最终会采用的轮廓，松手坐标参与判断。跨阶段未完成的笔画丢弃；失败不会扣灵力、运行肉鸽规划或创建半座阵。

## 防守与反馈

阵法冷却完成后等待敌人入阵，首次接触立即攻击，不再空转冷却。金阵集火残血；火阵群伤铺灼烧；木阵周期束缚；水阵减速留敌且不删除已有灼烧；土墙阻挡、承伤和反击。浓度与各阵攻击间隔详见浓度规则。

布局不显示路线虚线或地面边界辅助线。无遮挡时狼直接向营地前进，遇到障碍再寻路；土阵可贴边封路。详见 [有效阵域裁切与自然寻路](./13-ground-clipping-and-paths.md)。受伤血条保持可见，显示缠绕、减速、破防和镇压状态；持续灼烧数字短时合并，避免每帧刷屏。页脚记录阵法（含宝宝）、划线、反应（蒸汽及其余连携）的实际有效伤害，排除过量伤害。
