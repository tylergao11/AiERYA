# 实心土墙

更新：2026-09-13。用户确认：土阵圈内整块升起实体土墙，用来封路。

## 成形与封路

- 自由绘制闭合后，整个有效区域升起。长条形成长墙，宽圈形成宽土垒，轮廓跟随笔画。
- 顶面、立面和碰撞使用同一份有效阵域。墙体覆盖内部，狼不能走进中心，也不能从墙体内部开始的短线段穿行。
- 贴边仍保留空地内有效部分；不同片区分别形成实体，排除的孔洞和片区间的空隙保持开放。
- 外缘保留 0.55 世界单位的墙脚，再叠加狼身体半径检查间距。狼群能绕过开放出口，封死时普通狼和狼王破墙；精英短距离跃障仍需在整块墙体之外找到落点。
- 成阵消耗和灵力浓度机制沿用现有规则。土墙按总周长分摊投入，墙越长，同样投入下生命越低；整座阵共享生命，生命归零时整个墙体解除碰撞。
- 相克压制暂停土阵攻击，不让实体消失。火生土的修复和强化继续生效。
- 战斗迁阵检查目标占用，避免让实心土墙升在狼身上。落点被占时原阵保留，不消耗灵力和迁阵冷却。

## 表现

使用连续土质顶面和夯土立面代替沿边排列的石堆。墙体从地面升起，拥有固定可辨认高度、墙脚阴影和土层纹理；生命降低后裂痕加重，撤回或破坏时下沉消散。强化与压制改变土质色泽，实体高度始终保持。

顶面按深度切片，立面按轮廓细分参与角色遮挡排序。切片只服务绘制排序，视觉填充封合，不画网格和分块边线。裁切几何含多个片区与孔洞时，顶面完整保留这些形状。

## 实现与验证

- `src/game/earth-wall.ts` 提供统一的实体占用判断，由寻路、移动、攻击接触和迁阵共用。
- `src/render/earth-wall.ts` 构造土墙表面；`WardPainter` 管理其缓存、升起、状态和消退生命周期。
- `tests/earth-wall.test.ts` 覆盖整块内部阻挡、内部线段、片区与孔洞、大位移防穿、精英落点、压制与破坏、迁阵占用，以及所有顶面面积与有效阵域一致。
- `tests/edge-placement.test.ts` 和 `tests/wolf-vault.test.ts` 继续覆盖贴边封路、狼群破墙及短墙跃障。

本次完整测试 267 项通过，TypeScript 检查和生产构建通过。浏览器确认长条墙顶面连续填满、靠河土垒自动裁切，以及狼群在墙外绕行、接触反击和前后遮挡；控制台无错误。新增及修改的主要文件通过 UTF-8 无 BOM 检查。
