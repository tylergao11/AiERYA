# 阵灵作战与界面表现 · 当前确认

## 用户确认（2026-09-13）

1. 觉醒后化灵，机缘可共存。
2. 木、土、祖兽近战；金、水、火远程。
   并行玩法改动曾将全部阵灵设为近战，用户随后明确回复“按近远分工继续”。本条取代此前全近战方案；不要再次改回全近战。
3. 领悟用小动画举例，减少长文。继续使用五选二开局和波间三选一。
4. 手绘森林插画中作战，手机优先，低饱和、清楚的材质与动作；原阵完成化灵后不得继续伤害、阻挡或以光圈常驻。

## 实体与动作

- `spirit-profile.ts` 是近远分工的共同入口：近战射程 1.75，祖兽 2.2；远程射程 7、接近时尝试后撤到 4.5。移动、命中检查、动画使用同一份契约。
- 近战接敌、蓄势、接触出招、收招；远程蓄势、发射、飞行、命中。伤害按仿真时机落下，飞行中的弹体不会提前播放命中闪光。
- 移动与射线沿用空地、土墙碰撞；后撤逐步检查，不越界、不穿墙。木灵在身边生根，水弹在目标处生涡，火羽在目标处叠印爆燃，金剑沿弹道穿刺。
- 普通古阵觉醒后从 `world.wards` 移除，退出攻击、碰撞、寻路和撤阵退款。阵灵以 `originWard` 保存投入、古阵席位与成长；不能重复领取免费古阵。普通阵法与化灵合计占六席。
- `阵中藏灵` 可以保留古阵及追加灵体；中途获得该机缘时，仅在原位置仍可合法容纳阵法时恢复原阵，不穿插已占用区域或敌人。
- 化灵为短暂轮廓收束、材质碎光上升、灵体显形。移动用木鹿、土灵、祖兽的四帧行走图集；原地攻击继续使用攻击图集。

## UI 与镜头

- 波间卡片：名称、动画案例、一行结果、选择按钮；完整规则藏于“招式详情”，待生效条件与逆脉代价始终可见。全部普通领悟、机缘和突破有对应案例。
- 构筑中的已得领悟可展开查看案例；操作手记改为三步图解。
- 波次来袭、觉醒、领悟完成使用短墨色过场，不阻止操作，不延缓仿真。
- 重击、蒸汽爆炸、营地受击提供短衰减震屏，屏幕位移封顶 4.5 像素。持续伤害不震屏；划线时停用，HUD 不位移。遵循系统减少动态效果偏好。
- 390px 竖屏卡片图在左、文字在右，横屏三列；按钮保留触控空间，不要求通过悬停看关键规则。
