# 合围与双印的接触表现

合围保留两名真实参与宝宝、各自御令元素、第一名宝宝出手时的位置。两道短曲线沿真实来向在落点交汇，颜色来自各自的御令；它们是已经发生的攻击余迹，不额外制造弹体或伤害。第一名宝宝移动后，余迹仍从原来的出手位置接入。

双印用旧、新两种元素材质接到同一落点。招式名进入统一文字层，与伤害字共同避让，不额外写细小的五行字。旧印已经击杀目标时只显示一次旧印，场景和召唤栏都显示“旧印终结”，不虚构新御令接触，也不播放双印接续音。

为了看清协作关系，只在该次接触的 0.08 秒范围内压低相关宝宝重复的普通命中画面。完整同契合击、无关宝宝的攻击和后续攻击保留原有表现。缓冲数量有上限，退出与重置清理作用范围。

预览：`artifacts/visual-review/summon-coordination-review.html`。使用真实御令与接触结算，固定招式时间观察合围、双印和旧印终结；不推进完整对局，因此不作为对局数值或节奏验收依据。

验证：真实参与者和历史出手位置、旧印终结分支、材质快照、重复画面范围及清理、双印声音分支均有定向检查。与本轮特写等回归共 46 项通过，另筛选三个结算案例通过，生产构建通过。浏览器检查了 844×390 的合围、双印与旧印终结定帧，截图位于 `artifacts/visual-review/summon-pincer-contact.png`、`summon-seal-contact.png` 和 `summon-seal-lethal.png`。
