# 停时大招与划线范围结算

更新：2026-09-13。

## 万象齐发

- 战斗中按 **Q** 或点击「停时」，每波可以发动一次，下一波恢复。
- 冻结战场 3 秒：敌人、持续伤害、阵法与宝宝攻击、刷怪、回灵、状态与调息计时全部停止。玩家可以连续划线、切换五行。
- 停时内每笔免灵力、免调息，按落笔的元素保存轨迹，暂不造成伤害。倒计时结束时自动收下尚未松手的一笔。
- 结束后先凝聚 0.28 秒，所有轨迹在同一战场时刻按绘制顺序释放；总释放演出 0.85 秒后恢复战场时间。先火后水等连招保留顺序。
- 保留轨迹位置，将笔触命中半径加宽为原来的两倍。开局与波间不能发动，暂停菜单和切出窗口也暂停大招倒计时。

### 双倍效果

| 效果 | 大招规则 |
| --- | --- |
| 直接伤害、反应伤害、蒸汽爆炸 | 原有结算的两倍，构筑与灵力浓度照常参与 |
| 新施加的灼烧 | 每秒伤害两倍，时长不变，避免伤害与时长同时翻倍变成四倍总伤害 |
| 缠绕、减速、破防、削弱、阵法强化与压制 | 持续时间两倍；减速和破防比例保留正常安全上限 |
| 火生土修复 | 最大生命的 20% → 40%，不超过最大生命 |
| 土生金储存追击 | 3 次 → 6 次 |
| 主阵引动 | 被划中的每座主阵均触发，主动伤害两倍 |

同类效果刷新不能用普通时长覆盖尚未结束的大招效果。大招不更改普通划线已有的调息；空放消耗本波机会，重开清空全部轨迹与计时。

## 普通划线的范围修正

移除普通划线隐藏的 2/4/6 个目标上限。每条划线和圈内所有敌人都独立命中，同时处理接触到的所有阵法；笔触宽度擦到长阵边缘也算接触。

金保留首个目标完整伤害、其后目标半伤的穿透衰减，后续不再逐个指数衰减到近乎零。其他五行按各自基准和图形浓度结算。全场乱画仍会被长度或面积稀释，调息、灵力和持续阵法的职责保持。

五行反应按来源区分：每只怪、每座阵和自然来源各自触发；同一来源反复被笔迹覆盖只触发一次。不同地点的同类反应均保留，重叠反应对同一受害者取一份效果，防止同一笔反复刷伤害。多个直接命中的缠绕目标可以分别被斩木转换。泥沼保留不同交汇点，近邻重施合并。

阵师引阵从只取第一座主阵改成遍历全部接触到的主阵。怪物自身的五行状态优先；地面加成来自怪物当前所处阵域，远处的另一座阵不会覆盖其局部反应。

## 验证入口

- `tests/ultimate.test.ts`：阶段限制、每波次数、全战场冻结、免消耗蓄画、逐笔元素、命中加宽、五行双倍、修墙、爆炸、取消与恢复。
- `tests/stroke-aoe.test.ts`：每行十目标、两阵两怪同笔反应、异地与重叠反应、多目标斩木、擦边接触和同时引动两座主阵。
- `tests/drawing-input.test.ts`：倒计时收笔，松手后不重复释放。
- 原战斗平衡用例继续对照纯划金、纯阵法和五行配合，防止范围修正让阵法失去价值。

本轮完整测试 336 项通过，TypeScript 与生产构建通过。浏览器验证火、木、水连续蓄画，灵力保持 100，停时期间无伤害；释放时同一画面显示三笔加宽轨迹、群体伤害和蒸汽爆炸。暂停中倒计时保持，恢复后继续释放；控制台无错误。
