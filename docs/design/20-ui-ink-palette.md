## 色彩分工

| 用途 | 基准 | 使用方式 |
| --- | --- | --- |
| 面板 | 墨灰 `#1c2124` | 一整块表面，边缘轻微明暗；底部操作区略深 |
| 主文字 | 暖白 `#ddd9ce` | 名称与正文；标题保留楷书，说明使用系统无衬线字体 |
| 次文字 | 灰白 `#b4b5ad` | 效果说明与操作提示 |
| 辅助文字 | 灰青 `#929b99` | 波次、次数、分组与辅助说明 |
| 主要操作 | 旧金 `#bca77e` | 入山、迎战、返回；选中条与勾选使用同一色相 |
| 语义色 | 降低饱和度的朱、青、金、灰蓝 | 限于流派标记、五行字与稀有度，名称、整行底色和整圈边框共用中性色 |

## 界面规则

- 开局五选二：动画为左侧主视觉；右侧用分隔线区分五条天赋。查看态为细侧标，选中态为淡金底加实心勾选；稀有度还有文字，避免只能辨色。
- 领悟：统一细边框，名称比说明突出，只有流派小圆点与动画带语义色；完整规则按需展开。
- 构筑：天赋先显示名称与短结果；点击展开动画、完整机制和成长方向。普通、机缘与天授组合沿用同一阅读结构。
- 战斗 HUD：状态条与按钮统一墨灰材质，五行只强调字与选中边；低生命使用克制的红褐色。暂停、声音和帮助使用同一笔宽的线图标。
- 波次、暂停、帮助、结算、加载画面使用同套颜色。悬停只改变局部底色与细边，动画遵循减少动态效果偏好。
