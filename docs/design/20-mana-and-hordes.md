# 灵力投入、密集怪群与流派克制

2026-09-13。依据用户最新确认：短划少耗低伤，长划增加消耗与威力；大幅增加普通怪，保留割草感，同时让每个流派都有可应对的克制。替代旧版每次固定收费与主动冷却数值。

## 一笔的预算

- 手绘距离每 4 世界单位为一笔标准投入：杀伐 10 灵力，其余 12。四舍五入到 0.01 灵力，不设整笔最低收费；自动补齐的闭合线不增加投入。
- 投入份数 = `min(8, 手绘距离 / 4)`。每笔最多投入 8 份，限制停时长时间往返涂抹的预算；大于该距离仍能绘制，覆盖扩大而浓度下降。
- 伤害 = 元素基础威力 × 投入份数 × 范围浓度 × 构筑/反应倍率。
- 线长超过 16 时，浓度为 `16 / 线长`；闭合面积超过 16 时，浓度为 `16 / 面积`。小圈没有反向面积带来的免费暴击，短划也没有固定伤害底值。
- 施法降耗升级是价格优惠；轮转与停时则由天赋提供免耗，仍使用该笔本来的预算计算效果。
- 所有沿途目标都结算，金的第二个及之后目标为 50% 威力。重复经过同一目标只命中一次。
- 连续划线、切换元素、迁阵均无玩家操作冷却；自动攻击间隔、敌人蓄力和技能持续时间继续承担战斗节奏。
- UI 在绘制时显示本笔消耗与浓度折算后的威力。布局成阵仍采用原有固定投资、大小影响浓度的规则。

| 杀伐元素 | 标准投入的基础直接伤害 | 主要用途 |
| --- | ---: | --- |
| 金 | 42 | 精准收割、斩木、打断呼群；后续穿过目标减半 |
| 木 | 22 | 缠绕、木生火、打断封阵；低投入控制也缩短 |
| 水 | 16 | 减速与消耗燃烧换蒸汽范围爆炸 |
| 火 | 32 | 对密集目标完整群伤，接木相生，熔甲破防 |
| 土 | 30 | 击退、泥沼、打断猎灵，支援土墙 |

亲和与升级另乘。例如金亲和 +20% 的杀伐：0.4 单位短划花 1 灵力、首目标 5.04 伤害；4 单位花 10 灵力、50.4 伤害。短划适合补残血，不会凭小笔画获得完整一击。

基础自然恢复：杀伐 6/秒，其余 3/秒；纳气每级 +30%，狂澜使自然恢复 −20%。每个原生敌人死亡返 1 灵力。杀伐追击共享一次施法的回灵凭据，额外返还不超过本笔实付 60%，也受天赋绝对额度限制；免费笔画无此额外退款，召唤出来的狼没有回灵奖励。

## 防止极短笔画刷收益

修墙、引阵、交叉战痕、拟法、回锋与派生攻击跟随实际笔画威力；交叉引爆取前后两条战痕中较弱的预算。震裂、裂空等计次收益按短划投入比例累积；轮转和破招至少要半笔标准投入。藏剑输出、追锋、寄生跟随投入缩放。金阵不足一整次连击储量时不能向上取整触发完整追击。

水灭火仍会消耗灼烧/火源热量，换一次爆炸；重叠爆炸对同一敌人只取最强值，不递归引爆。短划可以省灵，交换出来的爆炸也相应较小。

## 怪群与克制

| 波次 | 原生数量 | 普通怪生命 | 普通怪扑咬营地伤害 |
| --- | ---: | ---: | ---: |
| 1 | 72 | 24 | 2 |
| 2 | 108 | 32 | 3 |
| 3 | 150 | 42 | 4 |

六只一组，组内间隔 0.16 秒；后续组逐步加快，原生与召唤狼合计最多 72 只存活。达到上限时延后生成，不删除敌人或跳过波次。继续挑战后数量最多 240，血量继续增长。每 18 只放入一只精英，生命为普通怪 6 倍；第三波第 72 只替换为 18 倍生命的狼王。

| 敌人 | 针对什么 | 玩家可以怎么解 |
| --- | --- | --- |
| 锋甲狼 | 直接划伤降低 70%，消耗杀伐的灵力 | 火克金积累有效破防，再集中输出；阵法、宝宝、反应与持续灼烧可以绕过锋甲 |
| 唤群狼 | 持续清杂效率不够，有限增援增加压力 | 金划蓄力中的木相打断；每只最多呼群两次，每次两只，增援不会再召唤 |
| 封阵狼 | 固定阵域与站桩宝宝被局部封灵 | 木破土打断；迁阵、离开禁区或击杀施术狼；禁区持续 3.5 秒 |
| 猎灵狼 | 在宝宝当前位置预告禁区，暂停其输出 | 土克水打断；宝宝离开范围、玩家亲自击杀猎灵狼；只针对灵体，持续 3 秒 |
| 狼王 | 土墙封路和紧密堆叠阵地 | 1.5 秒蓄力期间火克金破招；移动阵域，避免同时被砸；破阵为 24 + 阵法最大生命 42% |

精英控制效果为普通怪的 75%，狼王 50%，没有永久免控。蓄力元素从真实技能状态读取，受其他命中染色也不会丢失正确破招关系；角色头顶显示克制提示。禁区跟随施术者生命，击杀后立即解除。

## 验证与当前界限

`tests/mana-horde-balance.test.ts` 覆盖线长收费、无冷却连续施法、低灵力拒绝、24 目标群伤、锋甲/破防、三类蓄力打断、猎灵离区和击杀解除、短划修墙与连击预算。原有反应、停时、撤阵、寻路、波末清理测试已迁移到新的标准投入和怪量。

`tests/horde-simulation.test.ts` 使用真实寻路、攻击、自然恢复、随机升级与停时；不注入额外生命、伤害或资源。普通操作间隔 0.4 秒，停时也按此频率录入。固定种子三波结果：

| 策略 | 结果 | 营地生命 | 击杀数（含增援） |
| --- | --- | ---: | ---: |
| 杀伐只划金、不处理精英 | 第三波失败 | 0 | 279 |
| 杀伐组合五行、处理精英、使用停时 | 三波通过 | 33.5 | 332 |
| 阵师布阵 + 主动干预 | 三波通过 | 12 | 340 |
| 召唤布阵 + 主动干预 | 三波通过 | 76 | 338 |

这些结果验证可行策略与明显弱点，不代表所有随机天赋组合都有相同通关率。后续需要继续用玩家实测校准召唤流相对宽松的问题。

浏览器使用桌面机器模拟 844×390 手机横屏：六水阵与阵灵、34 只狼同屏时 59.1 FPS，300 样本 P95 24.4ms，无超过 34ms 的帧；逻辑均值 1.07ms，绘制 1.88ms。该场布局没有守住营地，败北后清空敌人与绘制停帧正常。此为桌面浏览器视口测试，不是手机真机性能结论。

证据位于 `artifacts/balance/`，完整验证命令：`npx vitest run --maxWorkers=4 --testTimeout=30000` 与 `npm run build`。
