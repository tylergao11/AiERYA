# 十波狼潮、精英词缀与灵力经济

2026-09-13。以用户本轮确认为准：取消波次预告；狼潮连续、分散、可局部收割；阵法作战耗损，剩余跨波保留；灵力按货币处理。本文取代早期“三波通关、自然回灵、撤阵固定返八成”的规则。

## 狼潮

完整一局十波，原生狼共 2,400 只，另有受上限约束的呼群与分裂幼狼。每波胜利结算固定恢复 50 灵力（最多至 100），领悟一次，再主动迎接下一波；第十波及继续历练的后续波次同样恢复。失败不发放，重抽、选择领悟和继续历练不会重复发放。第十波胜利后可带着已有构筑继续历练。前九波不能提前结算通关。

按用户要求，所有怪物生命在原数值上统一提高 50%。倍率在波次生命入口应用一次，精英、巨化、狼王、呼群援狼、分裂幼狼与十波后的继续历练均继承；各类怪物原有的相对生命倍率保持不变。

没有入口提示、倒计时、下一批预告或来袭横幅。三个入口区域交错进场，出生坐标、速度、侧向经过点各自有差异；途中采用较大分离距离，临近营地才收紧。队列阻塞时保留敌人，每帧最多补一个，不积攒成一整团突然吐出。全场共享 96 个活敌名额，呼群和死亡分裂同样受限。

第六波用更脆、更多的狼形成释放段。第十波狼王在末段入场，仍有普通狼继续涌入；只显示已经入场的狼王血条。敌人真正施法时的范围和可破招提示保留，同时最多两个施法读条。

## 精英词缀

第一波已有两只词缀精英，随后逐波增加；后段约一成敌人为精英，普通狼仍占主体。基础精英生命约为普通狼三倍；靠词缀产生目标优先级，避免全部堆成厚血怪。

| 词缀 | 实际行为 | 表现 / 应对 |
|---|---|---|
| 神速 | 移速 +45% | 青色拖尾；水减速、木束缚 |
| 巨化 | 生命 +35%，移速 -10% | 较大体型、金色标识；集中重击 |
| 再生 | 3 秒未受伤后，每秒回复 2% 最大生命 | 绿色回复符号；持续伤害阻断回复 |
| 狂暴 | 低于 40% 生命时，移速 +25%、扑咬 +50% | 红色脉动；残血优先收掉 |
| 分裂 | 死亡时散出两只脆弱幼狼 | 紫色标识、死亡反馈；幼狼不递归、不掉灵力 |

前两波仅神速、巨化；第三波起加入再生、狂暴；第五波起加入分裂和双词缀组合。巨化与再生不会叠在一起。旧有锋甲、唤群、封阵、猎灵职责仍存在，也能携带词缀；纯词缀精英不会额外偷带呼群或封阵能力。词缀随狼显示，具体数值与应对可在帮助面板查看。

## 灵力与耗损

- 初始灵力与固定上限均为 100，余额跨波保留。2026-09-13 按用户最新要求，所有流派的自然回灵、击杀收入、笔画返还、撤阵回收和奖励补给均在 100 封顶；超额部分直接舍弃，不留待消费后补发，账本和回灵提示只记录实得。三流派基础战斗回灵均为每秒 3；归元每级同时提高回灵与击杀收入 30%，逆脉同时降低两者 20%。灵资每次立即恢复 30，最多恢复至 100，不再提高上限。准备、领悟、暂停、停时不推进自然恢复。借命狂书的负灵力透支规则保留。
- 准备阶段灵力支出统一乘 2：普通布阵实际花费 28，阵法强度仍按标准投入 14 计算；赠阵与准备时移阵仍为免费。标准四步战斗划线仍为 3，实际随长度、蓄力和已有流派机制结算。预览、支付及残值回收使用实际价格。
- 原生狼击杀给收入；御灵、阵师基础为 1，杀伐使用自身的击杀收益参数。精英收入为基础的四倍，狼王二十五倍。援狼、分裂幼狼不产灵力；杀伐额外返还仍使用单笔共享预算。
- 只有准备阶段可主动花 60 灵力修营 20 点，上限 100 安危。余额不足、战斗中或营地已满时不能购买。
- 每座阵在实际战斗时间内持续耗损，150 秒耗完一整份初始耐久；每次实际阵法攻击额外消耗最大耐久的 1/160。伤害与耗损共同减少剩余耐久。
- 准备、领悟、暂停、停时不发生战斗耗损。跨波不恢复耐久；化灵仍耗损原阵耐久，耗尽后移除灵体并释放名额。
- 撤阵回收 = 实付价格 × 剩余耐久比例 × 80%。一次性赠阵仅赠一次，撤掉或耗尽后重建要支付价格，不能反复免费重建。
- 场内显示耐久条，准备时和低于 25% 时显示百分比；撤阵选择显示当前残值，页脚显示入账、支出和回收。

## 同流派额外技能

沿用战斗代码的真实触发，不凭 UI 定时播放：

- 千锋归一：显示合技进度、就绪和“蓄满三格命中触发”，收到交叉斩事件后显示技能名。
- 纯阵合鸣：两座邻近阵都蓄足 20 阵势且有敌，显示就绪；同系或相克笔画放势后，由另一座阵支付自身阵势合鸣。提示读取真实可用节点。
- 万灵同契：显示共鸣值、合击就绪、下一道御令触发；实际下令后显示合击反馈，战场由原有合击特效表现。
