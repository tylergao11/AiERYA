# 群灵合击的画面层次

三只宝宝集火同一个目标时，完整合击插画叠加会遮住近战动作。旧去重只比较坐标，又可能隐藏另一只宝宝的正常接触。此轮保留每次命中的归属，以一个主效果和逐只短接触表达集中攻击。

## 实现

- `summon-impact-buffer.ts` 按元素、目标、距离和时间归并大幅合击插画；保留各自命中事件，不改伤害或攻击时序。正常接触去重同时核对施法者和目标，回响不参与正常接触去重。
- 完整合击材质位于角色后方；前方保留刃线、碎屑和爪痕。次级接触为 0.28 秒，回响为 0.36 秒且降低透明度。祖兽即使作为次级接触，仍保留自身爪击。
- 命中特效最多保留 48 份，优先淘汰轻量效果，避免大量回响挤掉主合击。事件位置做快照，避免跟随实体后续移动。
- `spirit-lanes.ts` 按插画轮廓平滑分开飞行灵体，偏移上限 84 插画像素；地面近战宝宝脚点不变。阴影、发射点与御令锚点共用本体偏移。特写为偏移留出横向空间。此项只改变绘制，不改变射程、碰撞或寻路；密集队伍仍可能部分重叠。
- 离开战斗阶段清理在途弹体画面，避免上一波特效在奖励面板关闭后继续飞行。头像改为复用场景 WebP 图集。
- 同拍不同本体的起手声分别保留，按队伍本体材质数量平衡音量；近战携异元素御令仍有较轻的本体撞击，完整同契主音保持一次。详情及本轮 43 项检查见 `24-summon-audio.md`。
