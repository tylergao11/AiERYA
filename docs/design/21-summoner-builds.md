# 御灵：指挥、御令与构筑设计

2026-09-13。御灵已接入正式运行时；本文记录用户确认的规则、当前参数及验证边界。数值集中在 `src/game/summon-balance.ts`，不是十波难度已经定版的承诺。

## 已确认的方向

- 本任务负责召唤流的玩法、构筑、数值及自身美术；其他流派由各自任务负责。共享战斗接口与混搭效果需要兼容，不能覆盖另一流派的能力。
- 用户再次明确：召唤流所有美术、数值、特效、设计均由本任务负责。范围包括宝宝造型与动作、近远程攻击、受令与强化、召唤与蜕变、构筑选卡及演示、手机交互、成长和实战平衡。不能只提交规则，把效果或数值留给其他流派任务补齐。
- 点敌人免费指挥集火，点空地免费移动；划线消耗灵力，给宝宝灌注五行力量，划过敌人同时指定目标。
- 纯御灵的主动输出通过宝宝兑现；混搭杀伐保留手动伤害，不能使选中的杀伐机缘失效。
- 木、土、祖兽近战，金、水、火远程。灌注改变攻击效果，不改变宝宝本体元素、近远职责或外形身份。
- 五行常驻；开局五选二、自由混搭；波间三选一，不保证刷到某条路线。卡片用小动画和一句话举例。
- 阵师觉醒后古阵化灵，原阵退场；“阵中藏灵”才允许共存。御灵主宠从开局独立存在，不要求先画阵。
- 手机操作优先，背景、状态和动作清楚；不增加额外的复杂手势。

此前文档的“纯御灵直接划线伤害”“拟法立即复制玩家法术”“主灵旧蓄能条”已被下文的御令和共鸣取代。混搭杀伐仍保留其手动伤害。

## 纯召唤与共鸣：最终确认

用户所说“全属性同阵营”指**已选流派技能全部属于召唤系**，不是五行相同。火灵、水灵、土灵可以同队。

- 召唤天赋、六项召唤机制领悟，以及通用灵资、回灵、五行强化、五行反应领悟，均保留纯系资格。
- 获得杀伐或阵师天赋／技能即打破纯系，包括已领悟、暂未启用的跨流派技能。混搭已有能力继续生效。
- 共鸣上限 100。实际命中集火敌人获得 7 点、御令实际命中额外获得 15 点，按该灵体占全队基础战力比例折算；短御令按投入缩放。点按、空划、回响和合击本身不刷共鸣。
- 满共鸣可以保留；下一笔至少半份标准投入的御令触发**群灵合击**，每灵获得一次 2.8 倍御令，升华后 3.6 倍。仍须接敌或射程内出手，未使用的合击 12 秒到期；新一轮共鸣有 1.2 秒间隔。
- **万灵同契**：触发时为纯召唤，则每只灵体合击后额外追击一次，威力为该次御令的 35%。原目标已死可转向附近合法敌人；每灵一次，不递归。拟法原有复奏独立保留。
- 界面只有一条全队共鸣条，展示纯系资格、当前御令和满条提示。没有额外合击按钮；常态仍是点按指挥、划线强化。

## 体验目标

宝宝能自主防守，玩家通过站位、集火、御令，把一次普通交战变成围杀、破招或群体爆发。操作的收益应体现在接敌效率、保住营地和实际清怪结果中。

一次好看的行动有完整因果：玩家下令 → 灵力进入宝宝 → 近战接近／远程瞄准 → 攻击接触 → 敌人受击 → 追杀或回到防线。不能划线结束便在远处扣血，宝宝的攻击只是装饰。

构筑的变化分别回答：带谁、怎样合作、哪种御令更有效。首版保留三种先天神通、六项行为领悟，复用现有五行和数值成长；新增一条全队共鸣条，不增加装备、符文盘或宝宝技能栏。

## 基础指挥

| 操作 | 行为 | 约束与反馈 |
| --- | --- | --- |
| 点敌人 | 独立灵体锁定该敌，近战追击，远程在射程内输出 | 目标身上出现统一集火标记；不重置攻速、不赠送攻击 |
| 点空地 | 独立灵体前往集合点，移动优先于追敌 | 到达后在附近防守；近战在前、远程在后，避免叠成一团 |
| 划过敌人 | 指定最靠近落笔终点的被划中敌人，并灌注御令 | 一笔只指定一个主目标；闭环也只是一道御令 |
| 划向空地 | 在终点集合，并灌注御令 | 可提前强化后接敌；移动本身仍可通过免费点按完成 |
| 没有操作 | 宝宝自行接敌 | 集火目标死亡后转向附近威胁，不追出地图；空地集合指令生效时保留防守位置 |

绑定存续古阵的阵灵继续遵守阵域活动范围，只响应范围内的合法集火；独立御灵与已经化灵的古阵可以移动。界面不能对受阵域约束的灵体显示“已到达”或假装它正在全图追击。

指挥可以打断尚未出手的旧目标蓄势，但保留正常攻击间隔。已经射出的弹体继续检查原目标和碰撞，不因改令瞬移到新敌人身上。沉默停止攻击但允许撤离。目标死亡、离开地图、波次结束都应清理失效命令。

封灵或阵域受压会使尚未完成的蓄力失效，短暂解除也不会让旧任务补发；未发射的御令与攻击冷却保留。场景封印、宝宝栏、解除反馈和镜头处理见 `33-summon-restrictions.md`。

## 五行御令：让攻击变形

所有宝宝都能接受五种御令。本体技能仍有自己的特色，御令强化有限次攻击；不把火灵永久变成水灵，也不把近战土灵临时变成全图炮台。

| 御令 | 强化攻击的主效果 | 一眼看懂的演示 | 用途 |
| --- | --- | --- | --- |
| 金·破锋 | 锋刃重击，留下短暂破绽 | 土灵拳上凝金刃，一拳打出裂纹 | 集火精英；后续伤害利用破绽 |
| 木·缠生 | 命中生根，限制敌人移动 | 鹿角／弹体长出枝纹，接触处根须收紧 | 留住冲向营地的狼，衔接金斩木 |
| 水·回澜 | 命中形成短促聚流 | 水纹随爪或弹体卷出，把邻敌拉近 | 聚怪后接范围攻击；对燃烧目标可接蒸汽 |
| 火·焚羽 | 命中爆燃并留下灼烧 | 灵体局部燃起火纹，命中点出现有形火焰 | 清密集狼群，接水或木 |
| 土·震岳 | 命中震退，削弱短时扑咬威力 | 肢体覆上岩甲，接触处碎岩向外掀起 | 守营、解围；不另造一座常驻土墙 |

相生相克在宝宝真正命中时结算。相克打断也必须等到攻击到达，不能下令时就远程解除敌人蓄力。木、金、土、火的破招用途沿用敌人的真实蓄力元素；水聚流范围读取实际作用范围。

当前御令预算：

- 沿用统一灵力与按笔画长度付费；当前经济模块为“4 世界单位、3 灵力”，以 `ECONOMY.strokePrice` 为准。召唤不另造收费和自然恢复规则。
- 一份标准投入为每只受令宝宝提供两份强化储量。一次强化攻击最多消耗一份；余量不足一份时，额外伤害与控制按比例缩放，不免费向上取整。
- 每只宝宝最多保有四份待用储量，单份八秒到期。各份独立过期，短划不能刷新旧份的寿命；进入下一波清空。
- 新御令立即切换下一次强化攻击的元素，未消费储量保留原来的到期时刻；不把五种强化倍率常驻叠乘。换令本身不触发伤害、破招、回灵或领悟计数。
- 手动施法必须在扣费前计算全队可接收的容量，只为实际可注入的标准份数收费：实际份数为本笔投入与全队最大储量缺口的一半中的较小值，每只宝宝再按自己的缺口接收。显示“御令已足”时不扣费。例如主灵已满、伴灵仅缺一份储量，最多支付半笔费用。不能按单位数量叠加收费，也不能给已满单位刷新到期时间。
- 多宝宝受到同一份御令，但各自输出按身份预算计算。新增伴灵确实增加战力，不把主灵原有伤害平分给所有单位。
- 受令期间攻速为普通状态的 1.65 倍，合击待发时为 1.8 倍。火令覆盖 3.3 单位、最多五个邻敌，邻敌额外伤害为灵体本体基准的 100%；其他御令最多三个邻敌，合击最多六个。各自范围和控制仍不同。
- 混搭杀伐仍需支付完整手动施法费用；宝宝满令只停止接收额外储量，不阻止杀伐出手，也不能免掉杀伐的费用。
- 停时期间的笔画汇成有限的“群灵齐发”储备，按真实单位与攻击节奏依次释放。普通与齐发合计最多十六份／灵、每笔投入不超过现有上限；普通四份储量之外的额外储备仅本次齐发有效，不允许长涂抹得到无上限攻击。入灵时不直接扣敌人血量，解除停时后按既有攻击间隔消耗御令；独立五行顺序、容量和接触表现的定点检查见 `32-summon-command-feedback.md`。

这些预算隐藏在详情中。战斗界面只显示当前御令和简短储量提示，玩家的认知仍是“点按指挥、划线强化”。

## 三条构筑方向

三个开局都立即可用，后续随机领悟改变打法，不要求三张指定牌同时出现。方向可以混合，不做互斥职业树。

### 双生伴灵：协同围攻

主灵和伴灵并肩，准备阶段可以配置一近一远，也可以双远程。觉醒增加支援灵。视觉高潮是前排接住狼群、后排齐射，重点目标倒下后接着扑向下一只。

- **合围**：两只不同灵体在短时间内用强化攻击命中同一目标，追加一次协同夹击。一个御令凭据只触发一次，不按灵体两两组合重复结算。
- **追猎**：强化攻击击杀集火目标后，把集火转给近处下一敌，全队短暂加速接战；保留尚未用完的御令。只继承剩余资源，不白送完整的新御令。
- 现有协鸣提升攻击速度，火／水强化支持清群，金强化支持围杀精英。

成型案例：**木灵缠住精英 → 火灵命中形成合围 → 精英倒下 → 全队沿追猎目标继续推进。** 即使未抽到合围，两只宝宝也会响应同一集火指令，各自正常作战。

### 吞灵祖兽：养一只压阵主宠

主灵成为近战祖兽，真实接近后用爪击与践踏作战。有效击杀积印，完成一次明显蜕变。觉醒强化祖兽本身，不自动追加支援灵。

- **重扑**：祖兽受令后，下一次强化攻击带出前方扇形重击。突进必须实际移动并检查土墙，不能从远处直接命中。
- **吞势**：祖兽强化攻击击杀原生敌人，积累少量短时战意；达到三层时，下一次强化攻击成为一次重击，随后清空。只记实杀，余伤、尸体、召唤狼不反复供养。
- 灵威强化每次重击；土令保护营地，金令集中破防，火令补群伤。不能仅靠祖兽变大，实际仍是一下一下点杀。

成型案例：**土令震开围营狼群 → 击杀攒足战意 → 金令集中打一只锋甲精英 → 大幅爪击和碎岩爆开。** 祖兽之外获得双生等机缘时，保留祖兽并增加合法伴灵；“单宠路线”是倾向，不是删除另一项已选效果的理由。

### 拟法之灵：御令复奏

拟法不再立即复制玩家在远处画出的杀伤区域。它复奏的是宝宝亲自兑现的强化攻击：初始主灵获得一次较弱回响；兼有双生时，初始伴灵也能复奏，觉醒赠送的支援灵不自动获得复奏资格。

- **双印**：上一种御令真正命中后，保留一枚短时残印。换成不同御令且真正命中时，先释放弱化旧印，再结算本次新印；随后消耗残印。只保留一种，不维护五层元素栏。
- **余音**：复奏原定目标死亡时，回响可转到附近一个合法目标，不对尸体挥空；回响不能再生成回响，也不刷新双印。
- 现有涟漪、余烬、寄生等五行领悟继续围绕真实命中和死亡接续。纯御灵的“凝术”需要转为加强付费御令的额外部分，不能抽到一张只加强已经取消的手动伤害的牌。

成型案例：**火令实际点燃 → 留火印 → 切水令 → 旧火印复奏 → 水击引出蒸汽 → 余音追向附近残血狼。** 水火都属于基础可用能力；双印让连接更稳定，未抽到时仍能自行控制换令时机。

## 六项机制领悟的当前数值

以下数字已实现并接受对比实验，不代表所有随机构筑强度相同。追加伤害使用负责灵体的预算，原攻击成长只继承一次；派生不会再次递归触发派生。

| 领悟 | 首轮实验规则 | 升级方向／限制 |
| --- | --- | --- |
| 合围 | 两个不同灵体在 1.2 秒内各造成至少半份御令的有效命中，追加后命中灵体本次御令 35% 的夹击 | 共用御令凭据一次，最短间隔 2 秒；单灵时明确显示需要另一灵体 |
| 追猎 | 御令击杀集火目标后，6 单位内转火；队伍移动速度 +35%，持续 1 秒 | 同一击杀只触发一次；不能累乘移速、刷新攻击间隔 |
| 重扑 | 祖兽强化攻击向前方额外扫中最多三个邻敌，各为本体基准 40% 威力，再乘本次御令投入和强化倍率 | 保留接触距离、扇区、视线检查；不增加对主目标的重复结算 |
| 吞势 | 每个御令击杀积一层，三层后下次强化攻击额外 +60% 主击威力 | 战意上限三，五秒未接战消散；短划按投入比例积累，不跨波储存 |
| 双印 | 上一元素有效命中保留 4 秒，换令命中时先回放 25% 的旧御令效果 | 残印来源至少半份投入；新旧印共用本次追加预算，控制按比例，不再生成残印 |
| 余音 | 复奏目标死亡后，在落点附近 4 单位内选择另一合法敌人 | 同一回响只转移一次；不能越过宝宝射程或土墙 |

拟法开局的回响第一轮按原强化额外部分的 35% 预算、约 0.25 秒延迟验证，不重复完整基础普攻。双生伴灵先沿用现有 65% 输出份额，觉醒支援灵沿用 40%。祖兽先沿用当前基础倍率和 12 印蜕变，再用三条路线的实战结果决定调整。

六项机制领悟首版各一阶；避免连续抽到同一行为只看到更多数字。灵威、协鸣、驭令等现有成长继续承担稳定的数值提升。显示示例必须说明“这张牌会改变哪一步”，而不只是“攻击增强”。

## 抽取、混搭与后续成长

- 不提高到每波必出召唤牌，不固定发牌序列，不用隐藏保底替用户选好构筑。对比实验可以指定构筑，但正式开局和奖励仍随机。
- 六项领悟属于召唤成长。重扑／吞势需要祖兽，合围需要至少两灵，余音需要拟法；跨路线抽到时标明前提，允许留待机缘，不伪装成立即生效。双印与追猎可支持普通御灵。
- 推荐文字只给两个相关方向，例如“合围：适配双生、协鸣”；不会把其余选择锁掉。
- 觉醒改变队伍形态：常规添支援灵，祖兽强化本体。升华提高全队共鸣合击威力；卡片演示实际近战或远程动作。不因主命顺序不同而漏掉混搭突破。
- 当前战役为十波；召唤自动实战先验证前三波开局与第一次构筑变化，升华另有定向测试，不能声称前三波可自然抽齐整套牌。
- 召唤＋杀伐：一笔同时亲手攻击并授令，分别按自己的成长结算；回灵、反应次数、回响不能把同一笔登记两次。
- 召唤＋阵师：古阵能力照常生效；觉醒后的独立阵灵受令，共存阵灵受阵域限制。不能免费迁移一座仍在运行的阵法。
- 双生＋祖兽：祖兽负责重击，伴灵补控制或远射；新增单位不撤销祖兽。祖兽＋拟法：复奏祖兽的合法近战攻击，不生成远程假扑击。
- 相生相克领悟适配御令的第一次有效命中：按原始御令凭据计数，而非按宝宝数量或回响次数计数；原生普攻与派生不冒充新的手动御令。
- 熔金藏剑在后续御令真正命中时释放，一道原始御令最多消耗一剑；划线时不会让远处敌人提前受伤。

## 美术与手机界面

- 指令接收立即亮一次短促标记，保证玩家知道点到了；灵体身体上的符纹随后对应当前御令。战斗常驻信息只保留集火目标、集合点、当前强化状态。
- 双生：错开小幅出手节奏，合围在同一目标处合成一次明确撞击；多只灵体不能完全重合。
- 祖兽：接敌有重量、起手蓄势、爪击接触、身体回收；重扑与蜕变才提高震屏，普攻不连续摇画面。不可把跳跃直接当作攻击结算。
- 拟法：主攻击清楚，回响以较淡残像重复一次；双印先旧后新有可见次序，不能同时堆成一团白光。
- 近战御令附着爪、角、拳；远程御令附着弹体，火焰沿飞行方向拖尾，水弹命中后才起漩涡。不能所有效果都套同一个圆环。
- 领悟卡：名称 + 两至三步短案例 + 一行结果；前提与代价直接露出，数字细节可展开。颜色沿用克制的墨色底与局部五行色。
- 手机点按与划线使用屏幕距离区分，轻微手抖仍算点按；免费指挥不因为按得久而误触扣灵。绘制时显示可注入量与实际费用。
- 特写中按下时暂存看到的狼或地面。轻点按此意图集火或集合，不因镜头回位点到另一处；转成划线则从恢复后的普通视角取点。取消、切波和停时清除暂存，已死亡目标不会重新被锁定。

## 验证标准

1. **指挥收益**：同随机种子、同构筑、同投入，比较无人指挥、只点按、点按加御令；记录营地生命、击杀、漏怪、过关时间与宝宝伤害份额。纯御灵不靠偷偷保留直接划线伤害过关。
2. **构筑差异**：分别验证双生围攻转火、祖兽近战重扑、拟法元素复奏；同时检查三个开局在没有特定领悟时可玩。用真实抽取的多种种子检查成型频率和暂时无用的牌，不只测指定满配。
3. **经济**：短划投入按比例；满储量不白扣费；不同剩余储量的宝宝补充计价一致；换令不延长旧储量；反复点按、派生、召唤狼无法刷无限伤害或回灵。
4. **职责**：近战不能隔墙和超距命中，远程弹体先飞行后扣血；沉默时可撤，移动命令不被旧追敌覆盖。不能通过反复点击取消后摇提高实际攻速。
5. **组合**：双生＋祖兽、双生＋拟法、祖兽＋拟法、召唤＋杀伐、召唤＋阵师逐项检查；波末取消待发攻击，重开不残留御令。
6. **体验**：手机上能连续完成集火、撤离、切令、再进攻；截图确认布局，实际运行确认延迟、碰撞、动画时序与密集战斗性能。桌面缩小视口不能代替真机性能结论。
