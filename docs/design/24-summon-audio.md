# 御灵音效与招式配合

## 声音设计

召唤流使用独立材质音库，与游戏共用 AudioContext、音量设置和静音入口。普通攻击、御令强化、同契合击有不同强度；声音跟随真实发射与落点事件。

| 灵体 / 动作 | 声音表现 |
| --- | --- |
| 剑灵 | 短促刃鸣、金属共振 |
| 灵鹿 | 枝条断裂、木质撞击 |
| 水龙 | 浪拍、水滴滑音 |
| 凤凰 | 爆燃、细小火裂 |
| 石卫 | 低沉撞击、碎石颗粒 |
| 祖兽 | 喉音、沉重扑击 |
| 指向 / 移动 / 注灵 | 三种短回应 |
| 同契就绪 | 克制的上行提示 |
| 同契合击 / 吞势 | 主撞击、材质层、短暂压低其他声音 |
| 合围 / 追猎 / 双印 / 回响 | 各自短音型；回响音量较轻 |
| 本命穿刺 / 三印爆燃 / 践踏 | 接续刃鸣 / 二段燃爆与火裂 / 地裂碎石尾音 |
| 封灵 / 恢复 | 短促收束声 / 轻微上行解封声；全队同类状态合并播放 |
| 近战步行 | 灵鹿轻蹄碎叶、石卫砂砾石甲、祖兽厚重爪步；由实际落脚触发 |
| 祖兽吞灵 | 短促吸气与低沉颗粒收束，最后一份让位于蜕变音 |

`src/audio/summon-bank.ts` 定义原创建模音色和切片索引。运行 `node scripts/generate-summon-audio.mjs` 可重建 `public/audio/summon-materials.wav`：24 kHz、单声道 PCM，44 种声音各 2 个变化，共 88 段，2,400,086 字节。声音预先合成，命中帧只播放切片。新增音色追加在旧索引末尾，保留既有切片位置。

## 混音与生命周期

- 召唤音效最多同时播放 8 个声音，同类动作有短间隔。高优先级招式可替换较轻的声音。
- 起手声按宝宝本体区分。凤凰、水龙、灵鹿可在同拍分别发声，同一种本体材质在 0.07 秒内合并。按队伍不同本体材质的数量做平方根音量补偿，保留起手位置的左右声像；合击起手尾音在主撞击到来时一并压低。
- 同一道同契御令的主撞击只播放一次，后续宝宝保留材质命中。原生攻击与御令接触按宝宝 ID、目标 ID 去重；仅旧事件缺少身份时回退到落点。不同宝宝打在同一点不会仅因坐标相同就被当成重复接触；同种材质仍共享短间隔以控制密集噪声。
- 木、土与祖兽携带异元素御令时，元素命中下保留较轻的本体撞击层。祖兽已经领衔同契主音时，不再额外叠第二次兽爪重击；回响也不重复这一层。
- 主撞击现按金、木、水、火、土分别使用独立音型；祖兽保留兽吼与撕裂底音，叠加所携御令的元素材质。吞势和同契同帧时同契为主声，不再被较早发生的吞势限流吞掉。
- 主招式暂时降低其他召唤声部，并向共享混音器请求音乐压低。共享混音器自行限制重复请求。
- 左右声像限制在 ±0.55，保持手机与耳机上的主体清晰。土系和祖兽包含中低频谐波，避免只依赖极低频。
- 用户交互后解锁播放；静音、暂停、换波、重置、停时及销毁会清理声音。未解锁时不积压旧事件。
- 出场声音读取 `spiritSpawn` 的实体身份，不再靠“伴灵现身”等展示文字或坐标猜角色。异材质同时出场分别发声，同材质在 0.3 秒内合并，按队伍材质数做音量补偿。
- 领悟／开局面板期间仅保留仍存活实体的出场，以及最近一次主灵成长。共享音频引擎暂停后会异步恢复，必须收到实际 `running` 状态才消耗这些声音；关闭面板的同步调用不会把它们提前丢掉。攻击与脚步不进入这条队列。待出场最多八份，溢出优先保留本命；同材质成长音与出场音合并，重置、静音、停时和重新暂停清除。
- 资源失败时允许游戏继续，诊断接口报告失败；不会把失败伪装为可播放。
- 封灵与解除由真实状态变更驱动，普通每帧状态读取不发声；各自有全队 0.4 秒合并间隔，不给每只宝宝叠一份声音。暂停、静音时不积压恢复声。
- 脚步声由 `spiritStep` 表现事件触发，实际移动距离经过步态的落脚点才产生；飞行灵体、站立、瞬移和挥击不发脚步。全队共用 0.14 秒限流，优先级低于任何攻击，不能挤掉攻击声部。音色取本体身份，不随御令改成另一种材质；封灵后仍能听见撤离的脚步。

运行时文件：`src/audio/summon-audio.ts`；共享入口：`src/ui/audio.ts`。回响攻击新增可选事件标记，同时降低回响的画面透明度。

- 尚未完成整局数值验证；本次遵照要求没有跑对局。声音质感仍需结合实际试听判断。
