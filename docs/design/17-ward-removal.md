# 指定撤阵与八成回灵

布局和战斗中，点击「撤阵」后再点击任意已有阵法即可撤除。鼠标经过时高亮整座阵并提示退款；土阵的墙顶和墙面均可点选。多块裁切区域仍属于同一座阵，任意一块都能选中整阵，排除孔洞和区域间空隙。

撤阵模式支持连续点选；再次点击按钮、按 Esc、选择五行、暂停、开启停时大招或撤空全部阵法后退出。空地点击、拖拽、阶段切换和取消中的手势不施法也不撤阵。停时录入与释放期间禁用撤阵。

## 结算

- 每座阵在成交时记录 `Ward.paidCost`，与用于计算强度的 `power.investment` 分开；成阵扩展接口的 `cost` 同样提供实际支付金额。
- 返还实际支付的 80%，保留小数；14 灵力返还 11.2，灵力总量不能超过当前上限。显示实际收到的金额，满池截断时提示已达上限。
- 大小、剩余生命、后续强化和价格变动不影响已成交退款基数。
- 免费古阵退 0，保留原有免费重新布置与受损生命继承。付费古阵退款后，再次布置必须付费，不能通过免费恢复重复退款。
- `World.dismissWard(id)` 只对仍存在的阵结算一次；销毁和重开不走主动撤阵退款。布局的 `undo()` 也复用八成退款。
- 撤阵移除对应阵灵及扩展宝宝，保留其他阵和独立御灵宝宝；立即重建寻路场，释放土墙碰撞。已有短暂退场动画正常播放。
