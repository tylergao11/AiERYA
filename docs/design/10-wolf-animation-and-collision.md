# 狼群：动作、体型与场地碰撞

2026-09-12。本轮按用户追加要求处理狼群美术、动作、寻路、边界和碰撞。延续二维美漫插画；没有引入三维或新的第三方库。

## 三类狼

| 类型 | 轮廓 | 动作 | 当前出现方式 |
| --- | --- | --- | --- |
| 普通狼 | 灰蓝短毛，较轻的身体 | 快速压身与短扑 | 第一波起 |
| 精英狼 | 深色鬃毛、肩部伤疤、缺耳 | 独立蓄力越土墙，较短的受击停顿 | 第二波起，每六只中的第六只 |
| 狼王 | 银白厚鬃、宽肩与粗壮前肢 | 蓄力更久、咬合更重 | 第三波第一只；当前每场一只 |

暂用体型 1 / 1.18 / 1.5、生命倍率 1 / 1.55 / 3.2。集中放在 `src/game/wolves.ts`，后续玩法可直接调整。没有增加当前波次的总敌人数；营地每次受咬仍扣 5，土墙每次受咬仍扣 12。生命、速度与攻击节奏属于暂定参数，肉鸽改版时以玩法侧最终配置为准。

## 动作如何与实际战斗同步

攻击状态为 run → windup → lunge → bite → recover，以及 stagger。扑咬保持贴地，只在动作结束且仍有目标接触时结算一次咬合。目标墙已被摧毁、受击打断、定身或死亡，都会取消尚未发生的咬合。

- 奔跑帧按实际走过的距离推进，减速时随之变慢，停止移动时不空跑。
- 蓄力压低身体，攻击前冲贴地。仅精英狼的独立越墙状态抬起身体，阴影始终留在脚下投影处，落地带少量尘线。
- 受击用独立姿态、轻微后仰与短促提亮。硬直保护按类型分开，狼王能在每秒受击的情况下完成攻击，避免蓄力长反而永久被打断。
- 死亡优先于其他动画，依次后仰、倒下、伏地，尸体短暂保留后淡出。
- 攻击和伤害由模拟层驱动；画面刷新不能额外触发伤害。`ActorPainter` 只读状态。

## 精英狼越墙（按用户纠正后的语义）

跳跃用于跨过土墙，与扑咬分开。流程为 run → vaultWindup → vault → vaultRecover → run：接近土墙、压身蓄力、跨墙、落地，再继续寻路。越墙不调用咬合结算，也不扣土墙或营地生命。普通狼与狼王没有此能力，需要绕路或咬墙。

暂定参数集中在 `src/game/wolf-vault.ts`：最大跨越距离 4.5 世界单位、蓄力 0.26 秒、腾空 0.56 秒、收势 0.2 秒、独立冷却 4.5 秒，视觉高度 66 插画像素。过宽的土阵不能一次跳穿。

起跳前重新检查土墙与落点；轨迹的地面投影不穿河流、岩石或地图边界，落点检查体型和狼群占位。腾空期间预留落点；到达后再做落地检查。起跳前受击或定身取消蓄力；空中受击保留伤害，先落到合法位置再硬直，空中定身在落地后生效。空中死亡将尸体落在合法地面。燃烧随身体升降，湿润滴水从身体落向地面。

## 寻路与碰撞

`wolf-collision.ts` 使用脚下的圆形身体范围，不把尾巴与飞扬鬃毛当作硬障碍。不同类型有不同半径。清场多边形、河岸、岩块和土墙均参与身体检查。

地面移动、轴向滑动、击退、扑击与挤开修正共用同一套地形检查，每次位移细分到不超过 0.18 世界单位，避免薄墙穿越。精英越墙使用上述独立轨迹。狼群使用有限次数的位置修正减少身体重叠；尸体不阻路。密集接触允许极小数值误差，不承诺绘制出来的毛发永不相交。

`NavigationField` 按体型共享路径场，网格覆盖真实空地边界。土墙为高代价路径，有空路优先绕行；被围住时可以靠近咬墙。连续路段再检查身体空间，取消旧版营地附近直接走直线的地形绕过。新狼只在合法、未被占用的位置出现；没有位置时稍后重试，不扣掉应生成的敌人数。

土阵攻击范围同步到墙的外侧接触面，避免身体碰撞变大后狼站在墙外、土阵再也打不到它。

## 验证

新增狼群测试覆盖所有体型从三个入口抵达营地、身体边界、强位移穿墙、绕墙、狼群分离、出生占位、攻击时序、受击取消、狼王硬直保护、定身/死亡优先级、土墙接触伤害及波次类型。

原阵法单位销毁测试改为等候实际咬合，并从墙内出发；旧测试将狼放在墙上并要求首帧立即扣血，与现在的碰撞范围和蓄力动作不符。

追加越墙测试覆盖独立冷却、完整跨墙、不触发咬合、普通狼/狼王能力排除、落点占位、边界、受击与死亡落地、定身禁止起跳。浏览器验证包含动作预览按钮、实际战场中的三类狼、控制台与脚底校准。本轮最新结果记录在 `artifacts/visual-review/polish-review.md`；旧狼群检查保留为历史记录。
