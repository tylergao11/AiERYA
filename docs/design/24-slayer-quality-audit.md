## 混修输入、布局与重开复核

真实 DrawingInput + World 集成用例先复现 3 项失败，修正后通过；覆盖短划直接伤害并灌注、无预览帧的松手蓄力、点按容错、取消后的新手势和纯杀伐微划。最终 `tests-mixed-lifecycle-final.json` 的杀伐/输入/声音/特写相关 77 项全部通过，`npm run build` 类型和生产构建通过。
