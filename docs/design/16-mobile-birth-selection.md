# 手机开局气运与招式演示

本页按最新确认取代旧开局界面约定：**五选二、可跨流派组合、两项同时生效**。不用九选三，不保留备选，不保留上次稀有结果，不做抽取保底。

## 画面与操作

- 深蓝灰底、浅色正文；奇缘蓝、异数紫、天授金。颜色只突出天赋，不铺满高亮背景。
- 手机横屏：左侧实战动画与两行以内效果说明，右侧五条天赋；底部两格已选、重抽和入山。
- 手机竖屏：上方动画与说明，下方五条；底部确认区固定。较短屏幕只滚动内容区，横向不溢出。
- 点选天赋播放对应演示；再点取消。选满后查看其他天赋不自动替换已有组合。选满两项才可入山。
- 每次整批重抽清空选择。五项名称和神通互不重叠，避免低阶神通与包含它的天授同时占位。

## 动画边界

使用现有角色、狼、阵域、法术和受击渲染。`BirthDemoSimulation` 创建自己的 `World`，执行真实施法、阵法迁移、伙伴攻击与伤害事件；不会访问玩家本局的世界。候选灵根是亲和加成，演示允许使用玩家始终拥有的五行。

| 天赋 | 动画重点 |
| --- | --- |
| 一笔三锋 | 主锋命中，侧锋接续命中两侧狼 |
| 留痕成刃 | 横划留痕，竖划交叉引爆 |
| 借命狂书 | 低灵力时透支，增加划线威力 |
| 一图双阵 | 正副两座火阵持续攻击 |
| 阵中藏灵 | 古阵成形，阵灵同时助战 |
| 活阵随行 | 古阵迁移，落地冲击狼群 |
| 双生伴灵 | 主灵、伴灵分别攻击 |
| 拟法之灵 | 玩家先出手，灵体随后按自身元素复演 |
| 吞灵祖兽 | 示例从 11 印开始，击杀得到第 12 印后蜕变 |
| 三种天授 | 在同一演示中表现它包含的两项神通 |

每次循环约 4.8 秒，30 帧上限；资源共享缓存，切换时释放旧渲染订阅，入山后释放整个演示。开局遮罩后面的主场景停止重复绘制。页面隐藏时暂停；减少动态效果偏好下播放一次后停住，仍可手动重播。
